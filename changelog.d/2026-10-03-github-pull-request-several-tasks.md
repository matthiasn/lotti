### Changed
- **A pull request can be linked to more than one task, on purpose.** When
  you paste a pull request another task already has, Lotti now asks whether
  to link it here too — naming that task when it is not private — instead of
  refusing. The "+" picker still leaves pull requests other tasks have out,
  so nothing is linked twice by accident. A card whose pull request another
  task has too says which one, in amber rather than red: a reminder, not an
  error.
