### Changed
- **Merged and closed pull requests take a few lines in a task's context.**
  Coding prompts and the task agent now show a finished pull request by its
  title, outcome, size and a one- or two-sentence TL;DR, instead of its whole
  description, branch, checks and reviews; open pull requests keep every
  detail. The TL;DR is written once by the task agent's model, only where the
  task's category allows automatic inference, and syncs to your other
  devices. For a task with many merged pull requests, every agent wake and
  coding prompt is much smaller.
