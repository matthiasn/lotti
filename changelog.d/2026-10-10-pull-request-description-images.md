### Added
- **Pull request descriptions now show their images, and any of them can be
  added to the task.** A pull request's details used to stand a "not loaded"
  notice in place of every screenshot its description embeds. The images now
  load in place; a tap opens one full size, with zoom; a right-click — or a
  long press on a phone — offers "Add to task", which records that image on
  the task like a pasted picture, so it is analysed exactly as a pasted one
  would be. Only the image you add is ever analysed, never the rest of the
  description.
