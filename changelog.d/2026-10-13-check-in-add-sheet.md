### Added
- **A check-in's action bar now has the Add menu a logbook entry has.** Next
  to Dictate, Comment and Photo, a plus opens the same Add sheet as on any
  entry, so you can paste an image from the clipboard, start a timer, create
  a linked task, take a screenshot or add a note to a check-in. Actions that
  only make sense on a task, such as adding a checklist, are not offered. A
  task created this way shows in the check-in's timeline even when it is the
  only thing linked to it.
