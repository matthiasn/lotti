### Added
- **Tell a goal's agent what the goal is for.** Every goal page has an
  *About this goal* section where you write — or dictate — what the goal is
  about and how you want to be coached, for example "this is my journal for
  the season; ask me one guided question each morning". The agent reads it
  every time it writes to you, the morning briefing included, so a goal that
  is not about numbers still has somewhere to say what it is about. What you
  write there shapes the agent's focus, questions and tone, never the goal's
  status; it does not count as a check-in or as check-in time, and the page
  tells you when it has grown longer than the agent can read at once.
