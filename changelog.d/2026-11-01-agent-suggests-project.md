### Changed
- **The task agent now suggests a project for a task that has none.** It used to
  propose one only when your notes named a project. Now, when a task belongs to
  no project and its category has some, the agent looks at the task's title,
  notes and checklist and proposes the project it fits, like any other
  suggestion you confirm or decline. It proposes nothing when no project
  clearly fits.
