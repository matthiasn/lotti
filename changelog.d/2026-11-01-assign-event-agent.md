### Added
- **An event without an agent can now be given one, the way a task can.** An
  event only got an agent when its category had a default event agent at the
  moment it was created, so older events and events in other categories had
  no way to get a recap. The event page now offers **Assign Agent** in the
  recap card, with the same template and profile picker a task uses; an event
  that already has photos or notes gets its first recap right away.
