### Added
- **A task without a project now gets one offered.** Name a task "Prepare work
  presentation" in a category with a "Work" project, and the task header offers
  *Add to Work?* right beside *No project* — no need to mention the project
  first. One tap files the task there; the ✕ next to it says it does not
  belong, and that project is not offered for the task again. The match runs
  on your device, from the task's title, notes and labels against your
  projects' names, descriptions and the tasks already in them, and it stays
  quiet when no project clearly fits.
