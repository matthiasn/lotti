### Added
- **The task agent can now suggest creating a project you mention that doesn't
  exist yet.** Say "this is part of the Garden Shed project" in a task's notes or
  a recording, and if the task's category has no project of that name, the agent
  proposes creating it. Once you confirm, the project is created in the task's
  category under the name you used, already active, with the task in it. If the
  project does exist, the agent suggests moving the task into it instead, so
  names differing only in capitalisation or spacing don't produce duplicates.
