### Changed
- **Saying a task is done now gets you a "Done" suggestion to confirm.** When
  you dictate or write "let's close this" or "mark it done", the task agent no
  longer answers that it can't close the task. It suggests setting it to Done,
  shown with a large check mark so it stands out, and the task closes when you
  confirm. The agent still never closes a task on its own, and only you can
  mark one Rejected.
