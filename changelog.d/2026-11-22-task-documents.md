### Added
- **Tasks can hold documents.** "Write a document" in a task's Add sheet
  creates a markdown document on the task, such as a client one-pager, a
  meeting summary or a follow-up email. The task's new Documents section
  lists each one with its version and when it was last written. Open one to
  read it, edit it, copy its markdown out to paste elsewhere, or delete it.
  Every save keeps the earlier text as a version: History lists them, and
  any older one can be restored. An edit never overwrites a newer version
  saved meanwhile on another device.
- **The task agent drafts documents when you ask.** Say in a voice note or a
  note that you want a document — "a one-pager with the next steps from
  today's meeting" — or ask for changes to one, and the agent proposes the
  text from what the task holds. You read each version and confirm it
  before it becomes the document; it never rewrites a document on its own.
- **Ask for a document in the task's chat.** Ask the chat for a document,
  or for changes to one, and it proposes the new text there. A draft is
  confirmed only after reading it: "Read draft", in the chat or the AI
  summary, opens the full text, with "Create document" or "Use this
  version" at its foot. A document's page opens the task's chat beside it.
- **See what a new version changes before confirming it.** When the agent
  drafts a new version of a document, its page says so; "Review changes"
  lays the current text and the draft side by side, paragraph by paragraph,
  with what was added, removed and rewritten marked — or one under the other
  on a narrower window. Confirm it, discard it, or ask for changes in the
  task's chat. A draft written before you changed the document yourself
  can't overwrite your edit: the review offers to ask the agent to redo it.
