### Added
- **Tasks can hold documents.** "Write a document" in a task's Add sheet
  creates a markdown document on the task, such as a client one-pager, a
  meeting summary or a follow-up email. The task's new Documents section
  lists each one with its version and when it was last written. Open one to
  read it, edit it, copy its markdown out to paste elsewhere, or delete it.
  Every save keeps the earlier text as a version: History lists them, and
  any older one can be restored. An edit never overwrites a newer version
  saved meanwhile on another device.
- **The task agent writes documents when you ask.** Say in a voice note or
  a note that you want a document — "a one-pager with the next steps from
  today's meeting" — or ask for changes to one, and the agent writes it
  from what the task holds. The new text is the document straight away,
  with nothing to confirm; it never rewrites a document on its own, and it
  never replaces a change you made after it last read the document.
- **Ask for a document in the task's chat.** Ask the chat for a document,
  or for changes to one, and it is written as soon as the chat answers. A
  document's page opens the task's chat beside it.
- **See what the agent changed, and go back.** A version the agent wrote
  says so, on the task and on the document's page. "Review changes" lays it
  beside the version before it, paragraph by paragraph, with what was
  added, removed and rewritten marked, down to the words a rewritten
  paragraph changed — or one under the other on a narrower window. "Go back
  to v…" restores the earlier text, and nothing is lost either way: every
  version stays in History, where any two that follow each other can be
  compared the same way.
