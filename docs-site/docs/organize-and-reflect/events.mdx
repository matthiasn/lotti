# Remember meaningful events

Events give meaningful moments their own place in Lotti. Use an event for a
launch, trip, celebration, conference, or other moment you want to revisit. Use
tasks for the preparation and follow-up work around it.

Events are currently an optional feature. Open **Settings → Sections** and turn
on **Events**. The **Events** destination then appears in the
desktop sidebar and in the navigation launcher on mobile.

## Browse and filter your events

The overview is photo-led so that an event is recognizable before you read its
title. The nearest future event appears in the **Upcoming** hero. Past events
are grouped by year, newest first.

Use **Search events** to find an event by its text. **Filter events**, the
button beside the search field, opens a category filter: pick one or more
categories — or **Unassigned** — and apply them to narrow the complete
archive. Filtering is applied to the stored event collection, not only to the
cards currently visible on screen. Each card shows its category, so you can
tell **Penguin Operations** from **Fish Diplomacy** at a glance.

Lotti loads a long archive in pages and renders only nearby rows, so hundreds
of photo-rich events stay practical without loading every cover at once.

## Create an event

Select **New event**. A new event opens on its detail page, where you can add a
title, category, date and time, status, cover photo, and supporting entries.

Choose a title that names the moment rather than its preparation. For example,
**Project Waddle launch gala** is the event; **Recalibrate the zero-gravity fish
feeder** is a linked task.

The hero keeps the event's identity and main controls together:

- select the title to edit it;
- select the category or status pill to change it;
- select the language pill to choose the language the event's AI-written
  recap and proposals are kept in;
- select the date and time to reschedule the event;
- select a star to change the rating of a completed event; and
- open the overflow menu to change the cover or delete the event.

Changes save through the detail page; there is no separate form to reopen. A
rating appears after an event is completed, or whenever the event already has a
rating.

Under the hero, the event agent keeps an **AI summary** card — the same card a
task's agent uses. It shows the recap's short version with **Read more** for
the rest, **Open agent internals**, when it was last updated and **Update
now**. Below, **Proposed changes** lists what the agent suggests, such as
someone who was there or a note to add; accept or reject each one, or use
**Confirm all**. An event without an agent shows its own note instead, with
**Assign Agent** to give it one.

## Say who was there

The **People** section shows one chip per person linked to the event; select a
chip to open that person's page. **Edit people** — **Add people** while no one
is linked yet — opens **Who was there?** to change the list.

## Build a photographic record

The **Photos** section collects every image linked to the event in time order.
Select a thumbnail to open the full-screen viewer, then swipe between photos or
pinch to zoom. A large collection is capped to a compact preview; the last tile
shows how many more photos are available.

The cover is one of the event's linked photos. Until you choose one, Lotti
shows the newest linked photo and the header offers **Set cover**, so the
default is never mistaken for a choice. Open any photo full screen and tap
**Set cover** to make it the cover; the photo that already is the cover reads
**Cover** there, and the gallery badges it. **Change cover** in the overflow
menu opens the same picker, where you can also add a new photo.

## Follow the timeline and related work

<ManualScreenshot

  caption="Photos, notes, recordings, and follow-up tasks stay connected to the event without turning the event itself into a task."
/>

The timeline sorts linked entries from oldest to newest. It can contain:

- photos and their captions;
- notes;
- audio entries and voice notes; and
- time recordings, shown as a start, end, and elapsed span.

Select a timeline item to open its source entry. Everything you add to the
event comes from the bar along the bottom of the page: **Add a task** creates a
preparation or follow-up task already linked to the event and opens it, the
record button captures a voice memo for it, and the plus opens the **Add** menu
for a note, photo, audio entry, or other supported entry — all linked to this
event automatically.

The **Tasks** section appears once the first task is linked and lists the
event's preparation and follow-up work. Select a task to open it. On desktop,
tasks remain visible in a right-hand rail while you read the event; on mobile,
they follow the timeline in the same scroll.

## Event or task?

Use this distinction when deciding where something belongs:

| Use an event for… | Use a task for… |
| --- | --- |
| A moment with a date, photos, recap, and memory value | An action with a status, estimate, checklist, or work session |
| Project Waddle launch gala | Recalibrate the zero-gravity fish feeder |
| Europa sardine futures summit | Confirm the interplanetary sardine cargo pods |

Link the two when the work supports the moment. This keeps the event enjoyable
to revisit while its operational work remains actionable.
