# Run work as projects

Projects sit between categories and tasks. A category such as **Penguin
Operations** defines a broad area of responsibility; **Project Waddle** groups
the concrete tasks required to prepare the orbital penguin habitat.

## Find the project you need

Search matches project titles, stored project text, and category names. Under
the search field, **Current** hides completed and archived projects; **All**
brings them back. **Sort projects** orders the list by **Needs attention**,
**Target date**, **Recently updated** or **Name**.

The filter button narrows the list by **Status** or **Category**. Two
switches add more: **Only out-of-date summaries** keeps projects whose agent
summary is behind, and **Show inference profile** tags every project that has
an agent with the name of its inference profile. A filter stays inactive until
you select **Apply**.

<ManualScreenshot
  caseId="projects/filters"
  alt="Filter projects dialog with Status and Category rows, the Only out-of-date summaries and Show inference profile switches, and Clear and Apply, over the project list"
/>

Projects remain grouped by category after filtering. This makes similarly
named efforts easier to distinguish and keeps each operational area visible.
Each category header can collapse, and its map button opens **Explore
category** — the category's projects as a walkable district.

## Create a project

Select the **+** button in Projects, then enter:

- a required title;
- an optional category; and
- an optional target date.

<ManualScreenshot
  caseId="projects/create"
  alt="Create project form for Establish the lunar sardine reserve in the Penguin Operations category"
  caption="The creation form is a bottom sheet on mobile and a centered dialog on desktop."
/>

A new project starts **Open**. If its category has a project-agent template,
Lotti also provisions that agent after the project is saved. The project still
works normally when no matching template exists.

Use a title that describes the outcome or enduring mission. “Establish the
lunar sardine reserve” says more than “Sardines.”

## Edit project settings

Choose **Edit project** from a project detail to open the complete form editor
inside the Projects workspace. It covers the title, description, category,
status, and target date. Health, agent actions, proposed changes, and linked
tasks stay on the read-first project detail. **Cancel** and **Save** sit directly
below the form, and either action returns to that project.

## Understand project status

| Status | Use it when |
| --- | --- |
| Open | The project exists but active execution has not started. |
| Active | Work is currently moving and belongs in day planning. |
| Monitoring | No work is scheduled, but the outcome still needs observation. |
| On Hold | Work is paused for a known reason. |
| Completed | The intended outcome has been reached. |
| Archived | The project is retained for history but no longer operational. |

Select the status pill on the project detail page to change it. Status changes,
category changes, and target-date changes save immediately; there is no separate
save button on this read-first detail surface.

## Read project health and its report

<ManualScreenshot
  caseId="projects/detail"
  alt="Project Waddle detail with Active status and target date, its description, an AI summary card rated On Track with 91% confidence and one task blocked, and the Project Tasks list led by the blocked zero-gravity fish feeder"
  caption="Desktop keeps the project list and detail side by side. Mobile opens the same detail as a full page."
/>

The **AI summary** card brings the assessment and report together:

- **Project health** summarizes the agent's assessment, with rationale and
  confidence when available, and how many tasks are blocked;
- the report gives a current summary, and **Read more** expands it to its full
  content; and
- next steps and proposed changes call attention to concrete actions.

In Project Waddle, an On Track assessment is encouraging, but the
zero-gravity fish feeder is still a launch blocker. Read the rationale before
treating the band as a verdict.

The card itself keeps only **Open agent internals**, and **Update now** while
the summary is out of date. The model setup, automatic updates and how often
the agent updates live in the agent internals. Without an agent, the card
offers **Assign Agent** and the detail still shows the project's tasks and
description.

**Explore project**, beside the project menu, opens the project as a walkable
district with a building for each task.

## Add notes, recordings and images to a project

A bar along the bottom of the project page adds to the project directly:
**Record a voice note**, write a note, import an image, or the plus for the
**Add** menu with the rest. On a narrow screen the note and image buttons give
way to the plus. Everything added there is linked to the project, shows up in
its timeline, and is read by its agent.

## Keep project work in tasks

<ManualScreenshot
  caseId="projects/tasks"
  alt="Project Waddle task panel listing habitat inspection, zero-gravity fish-feeder calibration, and sardine cargo-pod confirmation with estimates and statuses"
/>

Project task rows show each task's title, short summary, estimate, and current
status. Select a row to open the task itself. Task details remain the source of
truth for descriptions, recordings, checklists, images, time records, and
cover art.

Assign a task to a project from the project control in the task header. Projects
are scoped by category, so give the task a category before choosing a project.
The task's agent can also propose it: mention the project in the task's notes or
a recording, and the agent suggests moving the task into it — or, when the
category has no project of that name, creating the project with the task in
it. Nothing changes until you confirm.
A task belongs to at most one project at a time; assigning another project
moves the link instead of duplicating it.

A project's category cannot change while it has linked tasks or a live project
agent. This protects membership and agent permissions from silently drifting
into different categories.

## Projects, categories, and tasks

Use the three levels deliberately:

- **Category:** a durable operational area such as Penguin Operations.
- **Project:** a multi-task outcome such as Project Waddle.
- **Task:** an executable unit such as recalibrating the zero-gravity fish
  feeder.

Avoid creating a project for a single simple action. Use one when multiple
tasks need a shared target date, status, progress rollup, or operational report.
