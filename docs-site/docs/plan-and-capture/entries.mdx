# Add entries and context

Lotti uses one **Add** menu for the things you capture during the day. Open it
from the journal for a standalone entry, or from a task to keep the new entry
attached to that task.

## Choose the entry that matches the material

| Action | Use it for |
| --- | --- |
| **Write a note** | Notes, decisions, observations, or pasted information |
| **Add a checklist** | A short set of concrete steps inside the current task |
| **Record a voice note** | A voice note that can be replayed or transcribed |
| **Add a task** / **Link a new task** | A separate outcome that needs its own status and context |
| **Add an event** | Something that happened, with its own photos and people |
| **Start a timer** | A timed work session linked to the current entry |
| **Import an image** | An existing image from the device |
| **Capture a screenshot** | A new desktop screenshot attached as an image entry |
| **Paste an image** | The image currently on your clipboard |

The menu is contextual. **Add a checklist** appears only on a task, and a new
task opened from a task is linked to it (**Link a new task**). On a task,
**Track time** on its action bar replaces **Start a timer**. **Add an event**
needs events to be switched on, **Paste an image** appears only while the
clipboard holds an image, and **Capture a screenshot** only on desktops that
support it.

## Keep context with the work

When you open **Add** from a task, Lotti links the new entry back to that task.
That keeps recordings, notes, images, and time records together on the task
detail page. Use a standalone journal entry when the material does not belong
to a specific outcome yet; it can be linked later.

See [Record audio](./recordings.mdx) for capture and transcription, or
[Work with tasks](../organize-and-reflect/tasks.mdx) for task structure, cover
art, and task links.
