# Choose Lotti's appearance

Open **Settings → Preferences → Theming** to control how Lotti looks. Lotti
ships a single carefully tuned theme with a light and a dark rendition, so the
only choice to make is which of the two the app should use, and when.

## Select a display mode

The switch shows three icons; hover or long-press one to see its name.

- The moon, **Dark Appearance**, always uses the dark rendition.
- The laptop — a phone on iOS and Android — is **Automatic**, which follows the
  operating system's current light or dark setting.
- The sun, **Light Appearance**, always uses the light rendition.

Automatic mode is useful when your device changes appearance on a schedule.
Lotti follows that change without any further input.

There is no Save button: the display mode persists as soon as you select it,
and it carries over to your other devices when sync is set up. The manual's
own light and dark switch is separate: it changes the documentation and
automatically chooses the matching screenshot variant, but it does not change
your Lotti settings.
