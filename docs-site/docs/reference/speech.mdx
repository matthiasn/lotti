# Choose the reading voice

When reading aloud is available, open **Settings → Preferences → Speech**. These
controls apply to what Lotti reads aloud — AI summaries and chat replies; they
do not change microphone capture or which AI provider transcribes a recording.
With the companion switched on, the separate Speech page is hidden and the same
settings live under **Settings → Preferences → Companion → Voice**.

The page starts with **Chat audio**: **Prepare chat audio automatically**
prepares new chat replies on this device so playback starts sooner. Audio
still plays only when you tap play.

## Choose a voice

**Cloud voices** lists, for each of your languages, the voice a cloud
read-aloud model speaks it in; tap one to hear or change it. The section stays
empty until an inference profile has a **Read aloud** model — until then
read-aloud uses the on-device voice.

The **On-device voice** reads for profiles without a cloud voice. Use the
**Female / Male** switch to browse the two groups, then select one of
the five numbered voices in that group. Switching groups only changes the
visible list; select a numbered voice to make it active.

The selected voice is a device-local preference. That lets each device use a
voice that suits its speakers and listening environment without changing the
choice on your other devices.

## Model download and privacy

The **On-device voice** uses **Supertonic 3**. Synthesis runs on the device, so
nothing is sent to a cloud speech service. When an inference profile has a
cloud read-aloud model, **Cloud voices** lists the voice for each of your
languages instead, and the text read aloud is sent to that provider. The
on-device model is large and is downloaded the first time it is needed, so
allow time, network bandwidth, and storage for that initial setup.

## Set the reading speed

Choose a speed from **0.5×** through **2×**. A setting of **1×** is the natural
rate; lower values slow the briefing down and higher values shorten it. The
selected speed is also stored only on the current device.

The read-aloud button appears only when the feature is enabled, the platform
supports the speech engine, and the task has a non-empty AI summary.
