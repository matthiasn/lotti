# Import health data

Health Import is available on iOS and Android. Open **Settings → Advanced →
Health Import**, choose a start and end date, then select the data family you
want Lotti to read from the phone's health-data store.

The available imports are:

- **Activity** for activity totals;
- **Sleep** for sleep samples;
- **Heart Rate** for pulse observations;
- **Blood Pressure** for blood-pressure readings;
- **Body Measurement** for body-metric readings; and
- **Workout** for recorded workouts.

Each row imports only its own data family over the displayed date range, and
reports what happened underneath its name once it has finished: how many samples
arrived, that there were none, that access was denied, or that the import
failed. **Import all** runs every row in turn. The **Last 7 / 30 / 90 days**
shortcuts set both dates at once; changing the range does not start an import by
itself.

## When a row brings back nothing

Your operating system asks for health-data permission the first time Lotti reads
a family, and Lotti can only read the types you grant. It asks **once per data
family** — blood pressure is a single request covering both the systolic and
diastolic readings — and it does not keep asking on its own afterwards. Tapping
a row retries the import and requests any permission that is still undetermined;
a type you have already answered for produces no new prompt, because the system
will not present it a second time.

A row that read nothing and has never brought in a single sample says **No data —
check Lotti's access in your health app**, and an **Open settings** button appears
below the list. This is a prompt to check rather than a verdict: Apple
deliberately does not tell an app whether it is allowed to read a type, so Lotti
cannot distinguish "you have no readings of this kind" from "you have turned this
access off". If you did turn it off, restore it in the health settings themselves
— on iPhone under **Settings → Health → Data Access &amp; Devices → Lotti**, on
Android in Health Connect. That is the only way back; Lotti cannot raise the
prompt again itself. Afterwards, tap the row to import.

Health Import is not shown on desktop because the underlying mobile health
stores are not available there. Imported observations can still be viewed in
the relevant Lotti dashboards after they have synced to another device.
