# Směrování práce pomocí modelů a profilů

Poskytovatel říká Lotti, kam se připojit. Model představuje jedno ID modelu
poskytovatele a jeho schopnosti. Profil inference potom přiřazuje tyto modely k
úlohám, pro které Lotti nabízí volby. Otázku „který model zpracovává zvuk?“
tak nemusíš řešit v každém úkolu a pravidle automatizace.

## Prohlížej uložené modely

Otevři **Nastavení → Nastavení AI → Modely**. Modely tvoří jeden seznam. Nad
ním ho zužují filtrační čipy, jeden pro každého poskytovatele, a čipy **Text**,
**Obraz**, **Audio** a **Uvažování**; vyhledávací pole najde poskytovatele,
modely i profily podle názvu.

Nahoře v Nastavení AI jsou tři ovládací prvky:

- **Souběžná probuzení agentů** omezuje počet různých agentů, kteří mohou
  současně spouštět inferenci.
- **Frekvence aktualizací** určuje, jak často se agenti úkolů aktualizují sami,
  když ji nenastavuje úkol ani jeho kategorie. **Nejvýše každou hodinu** se
  přesto aktualizuje hned po nahrávce, zastaveném časovači nebo úkolu
  označeném jako hotový.
- **Výchozí inferenční profil** je záloha pro agenty, kteří na tomto zařízení
  nemají nastavenou trasu inference.

Vyšší hodnota **Souběžná probuzení agentů** může zvýšit propustnost, ale také počet souběžných požadavků na poskytovatele a zátěž
místního zařízení. Nech ji raději nižší, když má poskytovatel přísné limity nebo
místní server modelů omezenou paměť.

## Přidej nebo uprav model

Vyber kartu modelu nebo ho přidej pomocí **+**. Definice obsahuje:

- připojení poskytovatele;
- zobrazený název a volitelný popis;
- přesné ID modelu u poskytovatele;
- nejvyšší počet tokenů dokončení;
- vstupní a výstupní modality; a
- příznaky schopností jako uvažování nebo volání funkcí.

Použij přesný identifikátor očekávaný poskytovatelem. Zobrazovaný název je jen
pro lidi; jeho změna nemění model, který poskytovatel spouští. Neuváděj podporu
obrázků, zvuku, nástrojů nebo uvažování, pokud je daný model a koncový bod
skutečně neposkytují.

## Sestav profil inference

Otevři **Nastavení → Nastavení AI → Inferenční profily**. Každý profil je
opakovaně použitelné pravidlo směrování. Přehled ukazuje model přiřazený ke
každé nastavené pozici.

<ManualScreenshot
  caseId="ai/profiles"
  alt="Profily inference Lotti Velení Project Waddle, Obydlí přednostně místně a Rybí diplomacie s jejich směrovanými modely"
  caption="Profily mohou optimalizovat odlišné hranice: široký cloudový profil, místní profil jen pro počítač nebo specializovaný profil uvažování."
/>

Uprav profil a přiřaď modely používaným schopnostem:

- **Uvažování** je povinný obecný textový model.
- **Model pro chat** odpovídá v chatech; když není nastaven, použije se model
  uvažování.
- **Uvažování (pokročilé)** může zpracovat práci výslovně žádající schopnější
  cestu uvažování.
- **Rozpoznávání obrázků** analyzuje obrázky.
- **Přepis** převádí zvuk na text.
- **Následné zpracování zvuku** opraví přepis podle slovníku řeči a napíše
  souhrn nahrávky; když není nastaveno, použije se model uvažování.
- **Generování obrázků** vytváří grafiku úkolů a další generované obrázky.
  Aktuální vestavěná cesta generování obrázků používá nastaveného vzdáleného
  poskytovatele; poskytovatele i odeslané reference proto vybírej se stejnou
  péčí jako u jiné cloudové inference.
- **Předčítání** je cloudový model řeči, který nahlas čte souhrny a odpovědi;
  když není nastaven, použije se hlas v zařízení.

V části **Automatizované dovednosti** na konci formuláře zapni, které
dovednosti — přepis a analýza obrázků — se s tímto profilem spouštějí samy.
Každá používá model své pozice, takže přepínač potřebuje tuto pozici vyplněnou.

Přepínač **Jen pro počítač** skryje profil na mobilních platformách,
což se hodí, pokud závisí na modelu dostupném pouze z pracovní stanice.
Připnutí zařízení slouží pro automatické zpracování synchronizovaného zvuku:
připínej jen zařízení, které nabízí poskytovatele vyžadované profilem. Bez
připnutého zařízení se synchronizovaný zvuk tímto profilem automaticky
nepřepisuje.

## Vyber model bez pamatování ID

Výběr modelu začíná poskytovatelem a ukazuje jen kompatibilní uložené modely.
Výběr v textové pozici profilu například nenabídne model určený pouze pro zvuk.

## Nastav výchozí profil kategorie

Kategorie může zvolit výchozí profil inference v **Nastavení → Definice →
Kategorie**. Agent běží na profilu, který mu byl vybrán; bez něj při každém
běhu následuje profil své kategorie, takže změna profilu kategorie přesune i
její agenty. Bez obojího se vrátí k **Výchozí inferenční profil** nahoře v
Nastavení AI. Vyber profil, jehož kombinace soukromí a schopností odpovídá kategorii, ne pouze
nejrychlejší možnost.

## Starší cesta profilu

Starší samostatná cesta **Inferenční profily** zůstává kvůli kompatibilitě a
upravuje stejné uložené profily. Ukazuje interní ID modelů a méně kontextu
závislostí než Nastavení AI, proto pro běžnou údržbu používej aktuální stránku
**Nastavení AI → Inferenční profily**.
