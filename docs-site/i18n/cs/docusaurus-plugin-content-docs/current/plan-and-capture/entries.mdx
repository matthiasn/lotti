# Přidávání záznamů a kontextu

Lotti používá jednu nabídku **Přidat** pro věci, které během dne zachytíš.
Otevři ji z deníku pro samostatný záznam nebo z úkolu, aby nový záznam zůstal
k tomuto úkolu připojený.

## Vyber záznam odpovídající materiálu

| Akce | K čemu ji použít |
| --- | --- |
| **Napsat poznámku** | Poznámky, rozhodnutí, pozorování nebo vložené informace |
| **Přidat kontrolní seznam** | Krátká sada konkrétních kroků uvnitř aktuálního úkolu |
| **Nahrát hlasovou poznámku** | Hlasová poznámka, kterou lze přehrát nebo přepsat |
| **Přidat úkol** / **Propojit nový úkol** | Samostatný výsledek, který potřebuje vlastní stav a kontext |
| **Přidat událost** | Něco, co se stalo, s vlastními fotografiemi a lidmi |
| **Spustit časovač** | Měřené pracovní sezení propojené s aktuálním záznamem |
| **Importovat obrázek** | Existující obrázek ze zařízení |
| **Pořídit snímek obrazovky** | Nový snímek plochy připojený jako obrázkový záznam |
| **Vložit obrázek** | Obrázek, který je právě ve schránce |

Nabídka je kontextová. **Přidat kontrolní seznam** se zobrazí jen u úkolu a nový
úkol otevřený z úkolu je s ním propojený (**Propojit nový úkol**). U úkolu
nahrazuje **Spustit časovač** akce **Sledovat čas** na jeho liště akcí.
**Přidat událost** vyžaduje zapnuté události, **Vložit obrázek** se zobrazí jen
tehdy, když je ve schránce obrázek, a **Pořídit snímek obrazovky** jen na
počítačích, které to podporují.

## Udržuj kontext u práce

Když otevřeš **Přidat** z úkolu, Lotti nový záznam s úkolem propojí. Nahrávky,
poznámky, obrázky a časové záznamy tak zůstanou pohromadě na stránce
podrobností úkolu. Samostatný záznam v deníku použij pro materiál, který ještě
nepatří ke konkrétnímu výsledku; propojit ho můžeš později.

Přečti si [Nahrávání zvuku](./recordings.mdx) o zachycení a přepisu nebo
[Práci s úkoly](../organize-and-reflect/tasks.mdx) o struktuře úkolu, titulních
obrázcích a propojeních.
