# Volba vzhledu Lotti

Vzhled Lotti řídíš v **Nastavení → Vzhled**. Lotti přináší jediný pečlivě
vyladěný motiv se světlou a tmavou podobou — zbývá jen zvolit, kterou z nich
má aplikace používat a kdy.

## Vyber režim zobrazení

Zvol jeden ze tří režimů:

- **Tmavé prostředí** vždy používá tmavou podobu.
- **Automaticky** následuje aktuální světlé či tmavé nastavení operačního
  systému.
- **Světlé prostředí** vždy používá světlou podobu.

Automatický režim se hodí, když zařízení mění vzhled podle rozvrhu — Lotti
změnu následuje bez dalšího zásahu.

Tlačítko Uložit zde není: režim zobrazení se uloží hned při výběru a se
zapnutou synchronizací se přenese i na tvoje ostatní zařízení. Vlastní
přepínač světlého a tmavého režimu příručky je oddělený: mění dokumentaci a
automaticky vybírá odpovídající variantu snímku, ale nemění tvoje nastavení
Lotti.
