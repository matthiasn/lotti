# Volba vzhledu Lotti

Vzhled Lotti řídíš v **Nastavení → Předvolby → Vzhled**. Lotti přináší jediný
pečlivě vyladěný motiv se světlou a tmavou podobou — zbývá jen zvolit, kterou z
nich má aplikace používat a kdy.

## Vyber režim zobrazení

Přepínač ukazuje tři ikony; jejich název uvidíš, když na ně najedeš myší nebo
je dlouze stiskneš.

- Měsíc, **Tmavé prostředí**, vždy používá tmavou podobu.
- Notebook – v iOS a Androidu telefon – je **Automaticky**, který následuje
  aktuální světlé či tmavé nastavení operačního systému.
- Slunce, **Světlé prostředí**, vždy používá světlou podobu.

Automatický režim se hodí, když zařízení mění vzhled podle rozvrhu — Lotti
změnu následuje bez dalšího zásahu.

Tlačítko Uložit zde není: režim zobrazení se uloží hned při výběru a se
zapnutou synchronizací se přenese i na tvoje ostatní zařízení. Vlastní
přepínač světlého a tmavého režimu příručky je oddělený: mění dokumentaci a
automaticky vybírá odpovídající variantu snímku, ale nemění tvoje nastavení
Lotti.
