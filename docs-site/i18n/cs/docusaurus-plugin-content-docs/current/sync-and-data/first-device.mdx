# Tvé první zařízení

:::note[Předpoklad]

Tato stránka vyžaduje homeserver Matrix (Synapse), který provozuješ ty nebo někdo, komu důvěřuješ, a k němu správcovský přístup. Pokud žádný nemáš, tato cesta pro tebe není dostupná — a nic jiného v Lotti na ní nezávisí.

:::

Každé zařízení po tom prvním dostává párovací kód ze zařízení, které už
používáš — ten postup popisuje [Přidat zařízení](./add-device.mdx). První je
jiné: neexistuje žádné jiné zařízení, které by kód vytvořilo. Synchronizace
Lotti je self-hosted, takže první kód přichází ze strany serveru — vytvoří
ho ten, kdo provozuje tvůj Synapse homeserver.

## Co dělá nástroj pro provisioning

Lotti obsahuje administrátorské CLI, **Matrix provisioner**, v repozitáři na
[`tools/matrix_provisioner`](https://github.com/matthiasn/lotti/tree/main/tools/matrix_provisioner).
Spuštěn adminem homeserveru:

1. vytvoří čerstvý účet Matrix vyhrazený pro synchronizaci,
2. vytvoří šifrovanou synchronizační místnost a
3. zapíše do souboru **provisioning bundle** — text, který Lotti přijímá
   jako párovací kód.

README vedle nástroje dokumentuje jednorázové nastavení, každý argument i bezpečné způsoby předání
administrátorského hesla. Minimální spuštění vypadá takto:

```bash
cd tools/matrix_provisioner
python provision.py \
  --homeserver https://matrix.example.com \
  --admin-user admin \
  --username lotti_sync_user42 \
  --output-file bundle.txt
```

Pokud vlastní homeserver neprovozuješ, tento krok není tvůj — požádej o
bundle toho, kdo server spravuje, a s cestou, kterou se k tobě dostane,
zacházej s péčí popsanou níže.

## Použij bundle jako svůj první párovací kód

Na zařízení, které se má stát tvým prvním, otevři **Nastavení → Nastavení
synchronizace → Zařízení** a zvol **Nastavit synchronizaci**. Vlož text
bundlu do pole pro kód — na telefonu, kde se nejdřív otevře fotoaparát, se
tam dostaneš přes **Raději kód vložit**. Zkontroluj, co kód popisuje, a
připoj se — u prvního zařízení tím cesta končí. Žádné ověření pomocí emoji
tu není: ověření porovnává dvě tvá zařízení, a máš zatím jen jedno.
Ceremonie se poprvé objeví, až budeš párovat druhé zařízení přes
[Přidat zařízení](./add-device.mdx).

Za vědění stojí i tohle: použití čerstvého provisioning bundlu
**rotuje heslo účtu** v rámci připojení. Soubor s bundlem je po prvním
použití vyčerpaný — platné přihlašovací údaje pak existují jen na tom
zařízení a každé další zařízení se páruje z existujícího přes
[Přidat zařízení](./add-device.mdx). Jakmile je první zařízení připojené,
soubor s bundlem smaž; zapomenutá kopie se už přihlásit nedokáže, ale není
důvod si ji nechávat.

Do toho prvního použití zacházej s bundlem jako s heslem: přihlašuje se jím
k synchronizačnímu účtu — drž ho mimo chaty, snímky obrazovky a sdílené
obrazovky.

## Na Linuxu: přihlášení bez bundlu

Předpoklad výše má jednu výjimku. Na Linuxu nabízí **Nastavit synchronizaci**
také **Místo toho se přihlásit účtem Matrix** a stejnou možnost nese i karta
prvního zařízení na stránce s párovacím kódem. Zadej adresu serveru, své
úplné Matrix ID (například `@jmeno:example.com`) a heslo k účtu: Lotti se
přihlásí, samo v tom účtu vytvoří šifrovanou synchronizační místnost a
skončí na stejné obrazovce prvního zařízení, na které končí i cesta přes
bundle. Žádný správce, žádný nástroj, žádný bundle — stačí jakýkoli účet
Matrix, který ovládáš, na vlastním homeserveru nebo na veřejném.

Dvě věci stojí za to vědět. Použij účet vyhrazený pro synchronizaci, ne ten,
přes který chatuješ: synchronizační místnost je jen další místnost v tom
účtu a všechno, co napíšeš, jde do ní. A heslo je tady tvoje vlastní —
zůstává v zabezpečeném úložišti tohoto zařízení, odchází jen na server,
který zadáš, a **nikdy se nerotuje**, na rozdíl od bundlu výše. Každé další
zařízení se i nadále páruje z tohoto přes
[Přidat zařízení](./add-device.mdx).
