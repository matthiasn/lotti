# Arbejd med tastaturgenveje

Lotti på desktop tilbyder et søgbart katalog over app-dækkende og
kontekstuelle kommandoer. Åbn **Indstillinger → Tastaturgenveje** for at se
hver kommando med bindingen opløst for din platform.

## Få hurtigt hjælp med en genvej

Tryk på **F1** eller **Primær + ?** for at åbne genvejsreferencen uden at
forlade dit aktuelle arbejde. **Primær** betyder Command på macOS og Control
på Windows eller Linux.

Ofte nyttige app-dækkende kommandoer inkluderer:

| Handling | Genvej |
| --- | --- |
| Åbn kommandopaletten | Primær + K |
| Opret en tekstindtastning | Primær + N |
| Opret en opgave | Primær + T |
| Åbn Opgaver, Daily OS, Projekter eller Vaner | Primær + 1 / 2 / 3 / 4 |
| Åbn Dashboards, Dagbog, Begivenheder eller Indstillinger | Primær + 5 / 6 / 7 / 8 |

De enkelte sider tilføjer kontekstuelle kommandoer som gem, opdater, søg
eller opret. Deres tilgængelighed kan afhænge af, hvad der aktuelt er i
fokus, eller om der er ugemte ændringer.

## Kør en kommando uden at forlade dit arbejde

Tryk på **Primær + K** for at åbne kommandopaletten over den aktuelle side.
Den kombinerer app-dækkende handlinger — oprettelse af poster, åbning af
opgaver, navigation og zoom — med kommandoer leveret af den aktive side.

Begynd at skrive for at indsnævre listen efter handlingsnavn, gruppe eller
tastekombination. Brug pil op og pil ned for at flytte markeringen, **Enter**
for at køre kommandoen og **Escape** for at lukke paletten. Fordi paletten er
kontekstuel, vises en kommando som **Gem** kun, når den fokuserede editor
aktuelt kan gemme.

## Søg efter handling eller tast

<ManualScreenshot
  caseId="keyboard-shortcuts/search"
  alt="Lottis tastaturgenvejskatalog filtreret med en søgeforespørgsel"

Brug søgefeltet, når du kender enten handlingen eller en del af dens
tastekombination. Kataloget i appen er autoriteten, hvis en binding ændres i
en senere version af Lotti.
