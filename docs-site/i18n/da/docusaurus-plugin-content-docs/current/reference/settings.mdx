# Find indstillinger

Indstillinger er grupperet efter den kapacitet, de styrer. Desktop bruger et
vedvarende træ med den valgte side ved siden af; mobil bruger en fokuseret
liste og åbner én indstillingsside ad gangen.

Vælg **Manual** i den sidste sektion af Indstillinger for at åbne denne guide
i din standardbrowser. På macOS giver **Hjælp → Manual** det samme link.
Guiden følger som standard dit systemsprog; vælg et andet sprog i
**Indstillinger → Avancerede indstillinger → Sprog** efter behov.

Almindelige destinationer inkluderer:

- **[Udseende](./appearance.mdx)** for lyst, mørkt og automatisk visningsvalg.
- **[Indspilningsstil](./recording-style.mdx)** for energikuglen eller den
  analoge måler, der vises under optagelsen.
- **[Tale](./speech.mdx)** for stemmen, modellen og hastigheden på enheden,
  der bruges til at læse opgaveoversigter højt.
- **[Tastaturgenveje](./keyboard-shortcuts.mdx)** for det søgbare katalog over
  desktopkommandoer.
- **[Fuldførelsesfejringer](./completion-celebrations.mdx)** for animationer,
  haptik, stilarter og deres interaktive legeplads.
- **[Avancerede indstillinger](./advanced-settings.mdx)** for funktionsflag,
  logning, vedligeholdelseshandlinger, onboardingdiagnostik og
  byggeoplysninger.
- **Kategorier** til planlægningsgrænser og **Etiketter** til tværgående tags.
- **Vaner** og **Dashboards** til refleksionsstrukturer.
- **AI-indstillinger** for udbydere, modeller, profiler og færdigheder.
- **Daily OS** for planlæggerens inferensprofil og hilsen.
- **Synkronisering** for forbindelses- og aktivitetstilstand.

Det præcise sæt kan variere afhængigt af platformens kapaciteter og aktiverede
funktioner.

## Administrér definitioner

Åbn **Indstillinger → Definitioner** for at administrere de strukturer, der
organiserer dine data. Kategorier sætter grænser for planlægning og privatliv,
etiketter markerer opgaver på tværs af kategorier, vaner definerer
tilbagevendende rutiner, dashboards arrangerer refleksionsvisninger, og
målbare værdier definerer de tal, du følger over tid.
