# Einträge und Kontext hinzufügen

Lotti verwendet ein gemeinsames **Hinzufügen**-Menü für alles, was du im
Tagesverlauf festhältst. Öffne es im Journal für einen eigenständigen Eintrag
oder innerhalb einer Aufgabe, damit der neue Eintrag dort verknüpft bleibt.

## Den passenden Eintrag wählen

| Aktion | Dafür verwendest du sie |
| --- | --- |
| **Notiz schreiben** | Notizen, Entscheidungen, Beobachtungen oder eingefügte Informationen |
| **Checkliste hinzufügen** | Eine kurze Folge konkreter Schritte in der aktuellen Aufgabe |
| **Sprachnotiz aufnehmen** | Eine Sprachnotiz zum Abspielen oder Transkribieren |
| **Aufgabe hinzufügen** / **Neue Aufgabe verknüpfen** | Ein separates Ergebnis mit eigenem Status und Kontext |
| **Termin hinzufügen** | Etwas, das passiert ist, mit eigenen Fotos und Personen |
| **Timer starten** | Eine zeitlich erfasste Arbeitssitzung zum aktuellen Eintrag |
| **Bild importieren** | Ein vorhandenes Bild vom Gerät |
| **Bildschirmfoto aufnehmen** | Ein neues Desktop-Bildschirmfoto als Bildeintrag |
| **Bild einfügen** | Das Bild, das gerade in deiner Zwischenablage liegt |

Das Menü berücksichtigt den Kontext. **Checkliste hinzufügen** erscheint nur in
einer Aufgabe, und eine aus einer Aufgabe geöffnete neue Aufgabe wird mit ihr
verknüpft (**Neue Aufgabe verknüpfen**). In einer Aufgabe ersetzt **Zeit
erfassen** in ihrer Aktionsleiste **Timer starten**. **Termin hinzufügen**
braucht eingeschaltete Termine, **Bild einfügen** erscheint nur, solange die
Zwischenablage ein Bild enthält, und **Bildschirmfoto aufnehmen** nur auf
Desktops, die es unterstützen.

## Kontext bei der Arbeit behalten

Öffnest du **Hinzufügen** innerhalb einer Aufgabe, verknüpft Lotti den neuen
Eintrag mit ihr. Aufnahmen, Notizen, Bilder und Zeiteinträge bleiben dadurch
gemeinsam auf der Aufgabendetailseite. Verwende einen eigenständigen
Journaleintrag, wenn Material noch zu keinem konkreten Ergebnis gehört; du
kannst es später verknüpfen.

Unter [Audio aufnehmen](./recordings.mdx) findest du Aufnahme und Transkription.
[Mit Aufgaben arbeiten](../organize-and-reflect/tasks.mdx) erklärt Struktur,
Titelgrafiken und Verknüpfungen.
