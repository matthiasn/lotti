# Lottis Erscheinungsbild wählen

Öffne **Einstellungen → Farbschema**, um Lottis Aussehen zu steuern. Lotti
bringt ein einziges, sorgfältig abgestimmtes Design mit einer hellen und einer
dunklen Ausführung mit. Du entscheidest nur noch, welche der beiden die App
wann verwendet.

## Einen Anzeigemodus wählen

Wähle einen von drei Modi:

- **Dunkles Erscheinungsbild** verwendet immer die dunkle Ausführung.
- **Automatisch** folgt der aktuellen Hell-/Dunkel-Einstellung des Betriebssystems.
- **Helles Erscheinungsbild** verwendet immer die helle Ausführung.

Der automatische Modus ist praktisch, wenn dein Gerät sein Erscheinungsbild
nach Zeitplan wechselt. Lotti folgt diesem Wechsel ohne weiteres Zutun.

Eine Schaltfläche zum Speichern gibt es nicht: Der Anzeigemodus wird direkt
nach der Auswahl gespeichert und gelangt über die Synchronisierung auch auf
deine anderen Geräte. Der Hell-/Dunkel-Schalter dieses Handbuchs ist davon
unabhängig: Er ändert die Dokumentation und wählt automatisch das passende
Screenshot-Motiv, aber nicht deine Lotti-Einstellungen.
