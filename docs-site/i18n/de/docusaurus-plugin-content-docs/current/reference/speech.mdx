# Vorlesestimme wählen

Wenn Vorlesen verfügbar ist, öffne **Einstellungen → Persönliche Einstellungen →
Sprache**. Diese Optionen gelten für alles, was Lotti vorliest –
KI-Zusammenfassungen und Chat-Antworten. Sie ändern weder die Mikrofonaufnahme
noch den KI-Anbieter für Transkriptionen. Ist die Begleitung eingeschaltet,
ist die eigene Seite Sprache ausgeblendet, und dieselben Einstellungen liegen
unter **Einstellungen → Persönliche Einstellungen → Begleitung → Stimme**.

Die Seite beginnt mit **Chat-Audio**: **Chat-Audio automatisch vorbereiten**
bereitet neue Chat-Antworten auf diesem Gerät vor, damit die Wiedergabe
schneller startet. Abgespielt wird trotzdem erst, wenn du auf Wiedergabe
tippst.

## Eine Stimme wählen

**Cloud-Stimmen** listet für jede deiner Sprachen die Stimme, in der ein
Cloud-Vorlesemodell sie spricht; tippe auf eine, um sie anzuhören oder zu
ändern. Der Abschnitt bleibt leer, bis ein Inferenzprofil ein Modell für
**Vorlesen** hat – bis dahin nutzt das Vorlesen die Stimme auf dem Gerät.

Die **Stimme auf dem Gerät** liest für Profile ohne Cloud-Stimme. Wechsle mit
**Weiblich / Männlich** zwischen beiden Gruppen und wähle dann eine
der fünf nummerierten Stimmen. Der Gruppenwechsel zeigt zunächst nur die andere
Liste; erst die Wahl einer Nummer aktiviert die Stimme.

Die gewählte Stimme ist eine lokale Geräteeinstellung. So kann jedes Gerät eine
Stimme verwenden, die zu Lautsprechern und Umgebung passt, ohne deine anderen
Geräte zu verändern.

## Modelldownload und Datenschutz

Die **Stimme auf dem Gerät** nutzt **Supertonic 3**. Die Synthese läuft auf dem
Gerät, es wird also nichts an einen Cloud-Sprachdienst gesendet. Hat ein
Inferenzprofil ein Cloud-Vorlesemodell, listet **Cloud-Stimmen** stattdessen die
Stimme für jede deiner Sprachen, und der vorgelesene Text wird an diesen Anbieter
gesendet. Das große Modell auf dem Gerät wird beim ersten Bedarf
heruntergeladen. Plane dafür Zeit, Netzwerkvolumen und Speicherplatz ein.

## Lesetempo einstellen

Wähle ein Tempo von **0,5×** bis **2×**. **1×** entspricht dem natürlichen
Tempo, niedrigere Werte verlangsamen und höhere verkürzen das Briefing. Auch
diese Auswahl bleibt auf dem aktuellen Gerät.

Die Vorleseschaltfläche erscheint nur, wenn das Feature aktiviert ist, die
Plattform die Sprachengine unterstützt und die Aufgabe eine nicht leere
KI-Zusammenfassung besitzt.
