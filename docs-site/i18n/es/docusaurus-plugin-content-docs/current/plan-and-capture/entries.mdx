# Añade entradas y contexto

Lotti usa un único menú **Añadir** para todo lo que capturas durante el día. Ábrelo desde el diario para crear una entrada independiente, o desde una tarea para que la nueva entrada quede vinculada a ella.

## Elige la entrada que corresponda al material

| Acción | Para qué usarla |
| --- | --- |
| **Escribir una nota** | Notas, decisiones, observaciones o información pegada |
| **Añadir una lista de comprobación** | Un conjunto breve de pasos concretos dentro de la tarea actual |
| **Grabar una nota de voz** | Una nota de voz que puedes volver a escuchar o transcribir |
| **Añadir una tarea** / **Vincular una tarea nueva** | Un resultado independiente que necesita su propio estado y contexto |
| **Añadir un evento** | Algo que ocurrió, con sus propias fotos y personas |
| **Iniciar un temporizador** | Una sesión de trabajo cronometrada vinculada a la entrada actual |
| **Importar una imagen** | Una imagen existente del dispositivo |
| **Hacer una captura de pantalla** | Una nueva captura de escritorio adjunta como entrada de imagen |
| **Pegar una imagen** | La imagen que tienes ahora en el portapapeles |

El menú es contextual. **Añadir una lista de comprobación** solo aparece en una tarea, y una tarea nueva abierta desde una tarea queda vinculada a ella (**Vincular una tarea nueva**). En una tarea, **Registrar tiempo** en su barra de acciones sustituye a **Iniciar un temporizador**. **Añadir un evento** requiere que los eventos estén activados, **Pegar una imagen** solo aparece mientras el portapapeles contiene una imagen, y **Hacer una captura de pantalla** solo en los escritorios que lo admiten.

## Conserva el contexto junto al trabajo

Al abrir **Añadir** desde una tarea, Lotti vincula la nueva entrada con ella. Así, grabaciones, notas, imágenes y registros de tiempo permanecen juntos en la página de detalle de la tarea. Usa una entrada independiente del diario cuando el material aún no pertenezca a un resultado concreto; podrás vincularla más tarde.

Consulta [Grabar audio](./recordings.mdx) para la captura y la transcripción, o [Trabajar con tareas](../organize-and-reflect/tasks.mdx) para conocer la estructura de tareas, las portadas y los enlaces entre tareas.
