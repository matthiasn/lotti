# Elige la apariencia de Lotti

Abre **Ajustes → Preferencias → Temas** para controlar el aspecto de Lotti.
Lotti incluye un único tema cuidadosamente ajustado, con una versión clara y
otra oscura, así que solo tienes que decidir cuál de las dos usa la aplicación,
y cuándo.

## Selecciona un modo de visualización

Elige uno de los tres modos:

- **Apariencia oscura** siempre usa la versión oscura.
- **Automático** sigue el ajuste claro u oscuro actual del sistema operativo.
- **Apariencia clara** siempre usa la versión clara.

El modo automático es útil cuando tu dispositivo cambia de apariencia según un
horario: Lotti sigue ese cambio sin que tengas que hacer nada más.

No hay botón Guardar: el modo de visualización se guarda en cuanto lo
seleccionas y, con la sincronización configurada, llega también a tus demás
dispositivos. El interruptor claro/oscuro del propio manual es independiente:
cambia la documentación y elige automáticamente la variante de captura
correspondiente, pero no modifica tus ajustes de Lotti.
