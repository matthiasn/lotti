# Encuentra los ajustes

Los ajustes se agrupan por la capacidad que controlan. El escritorio usa un árbol
persistente con la página seleccionada al lado; el móvil usa una lista centrada y
abre una página de ajustes cada vez.

Elige **Manual** en la sección final diferenciada de Ajustes para abrir esta guía
en tu navegador predeterminado. En macOS, **Ayuda → Manual** ofrece el mismo
enlace. Por defecto, la guía sigue el idioma del sistema; elige otro idioma en
**Ajustes → Ajustes avanzados → Idioma** cuando lo necesites.

El nivel superior muestra, en este orden:

- **[Primeros pasos](../getting-started/onboarding.mdx)** para volver a
  reproducir el flujo de bienvenida.
- **Secciones** para activar o desactivar partes completas de la
  aplicación, como Hábitos o Proyectos.
- **Ajustes de IA** para proveedores, modelos, perfiles y habilidades.
- **Agentes** para plantillas, instancias y supervisión de agentes.
- **Daily OS** para el perfil de inferencia y el saludo del planificador.
- **Ajustes de sincronización** para el estado de conexión y actividad.
- **Definiciones** para categorías, etiquetas, hábitos, paneles, medibles y el
  diccionario de voz.
- **Preferencias** para [Temas](./appearance.mdx) (modos de visualización
  claro, oscuro y automático), [Animaciones](./completion-celebrations.mdx),
  notificaciones, [Estilo de grabación](./recording-style.mdx),
  [Habla](./speech.mdx) y [Atajos de teclado](./keyboard-shortcuts.mdx).
- **[Configuración avanzada](./advanced-settings.mdx)** para indicadores de
  configuración, registro, acciones de mantenimiento, diagnósticos de
  incorporación e información de compilación.
- **Manual**, que abre este manual en tu navegador.

El conjunto exacto puede variar según las capacidades de la plataforma y las
funciones activadas.

## Activar y desactivar secciones

Lotti empieza con poco. Abre **Configuración → Secciones** para añadir
las partes que quieras: Daily OS, Proyectos, Metas, Hábitos, Paneles,
Personas y Eventos. Cada sección que actives tendrá su propio lugar en
la navegación, en el orden que muestra la lista.

Desactivar una sección la oculta junto con su entrada de navegación. No
se borra nada de lo que registraste allí, y al volver a activarla todo
sigue igual.

## Gestiona las definiciones

Abre **Ajustes → Definiciones** para gestionar las estructuras que organizan tus
datos. Las categorías fijan límites de planificación y privacidad, las etiquetas
marcan tareas entre categorías, los hábitos definen rutinas recurrentes, los
paneles organizan vistas de reflexión y los medibles definen los números de los
que haces seguimiento.
