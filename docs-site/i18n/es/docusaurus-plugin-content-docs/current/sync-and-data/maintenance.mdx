# Mantenimiento de Sync

Abre **Ajustes → Ajustes de sincronización → Mantenimiento** para reparaciones
y limpiezas a nivel de base de datos. Estas acciones no forman parte del
emparejamiento habitual ni de la sincronización diaria. Antes de usarlas, deja
que terminen las escrituras en curso y guarda una copia de seguridad reciente de
los datos que no puedas recrear.

## Elige la reparación más limitada

- **Eliminar la base de datos de sincronización** borra la base de datos de
  sincronización local. Es una recuperación local destructiva, no una forma
  normal de desconectar un dispositivo.
- **Sincronizar valores medibles, paneles, hábitos, categorías y ajustes de IA**
  vuelve a enviar esa configuración compartida. Un diálogo te deja elegir qué
  tipos incluir —también etiquetas y filtros de tareas guardados— antes de
  elegir **Iniciar sincronización**.
- **Historial de mensajes** vuelve a poner entradas en cola para tus otros
  dispositivos. Elige un intervalo —**Todo**, **Últimos 30 días** o
  **Personalizado** con un inicio y un fin— y los tipos de entidad que incluir,
  y después **Iniciar**. Si algunas entradas fallan, **Reintentar entradas
  fallidas** repite solo esas.
- **Llenar registro de secuencia de sincronización** indexa las entradas
  existentes para que el relleno pueda responder a peticiones de entradas
  creadas antes de que existiera el seguimiento de secuencias.
- **Purgar elementos enviados antiguos de la bandeja de salida** borra las filas
  ya enviadas de la bandeja de salida con más de 7 días y libera espacio en
  disco. Los elementos en espera o fallidos se conservan.

Empieza por la operación más pequeña que encaje con el síntoma. Un adjunto
atascado corresponde a la
[bandeja de salida](./sync.mdx#inspecciona-la-bandeja-de-salida); los huecos de
secuencia persistentes, al Relleno de sincronización; y dos ediciones
simultáneas válidas, a los [conflictos](./conflicts.mdx). Eliminar la base de
datos de sincronización debería ser un reinicio local de último recurso, hecho
con un par fiable y una copia de seguridad a mano.

Después de una reparación, vuelve a **Estadísticas de Matrix**, comprueba que el
trabajo aplicado avanza y la cola se vacía, y que la bandeja de salida y el
número de faltantes del relleno se estabilizan.
