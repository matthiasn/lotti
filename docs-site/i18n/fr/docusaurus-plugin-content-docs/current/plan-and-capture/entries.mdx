# Ajouter des entrées et du contexte

Lotti utilise un même menu **Ajouter** pour les éléments que tu captures dans la journée. Ouvre-le depuis le journal pour une entrée autonome, ou depuis une tâche pour garder la nouvelle entrée liée à cette tâche.

## Choisir l'entrée adaptée au contenu

| Action | À utiliser pour |
| --- | --- |
| **Écrire une note** | Des notes, décisions, observations ou informations collées |
| **Ajouter une liste de contrôle** | Un court ensemble d'étapes concrètes dans la tâche actuelle |
| **Enregistrer une note vocale** | Une note vocale à réécouter ou transcrire |
| **Ajouter une tâche** / **Lier une nouvelle tâche** | Un résultat distinct qui a besoin de son propre statut et contexte |
| **Ajouter un événement** | Quelque chose qui s'est passé, avec ses propres photos et personnes |
| **Démarrer un minuteur** | Une session de travail chronométrée liée à l'entrée actuelle |
| **Importer une image** | Une image existante de l'appareil |
| **Faire une capture d'écran** | Une nouvelle capture d'écran sur ordinateur, jointe comme entrée image |
| **Coller une image** | L'image qui se trouve actuellement dans ton presse-papiers |

Le menu est contextuel. **Ajouter une liste de contrôle** n'apparaît que sur une tâche, et une nouvelle tâche ouverte depuis une tâche lui est liée (**Lier une nouvelle tâche**). Sur une tâche, **Suivre le temps** dans sa barre d'actions remplace **Démarrer un minuteur**. **Ajouter un événement** nécessite que les événements soient activés, **Coller une image** n'apparaît que lorsque le presse-papiers contient une image, et **Faire une capture d'écran** uniquement sur les ordinateurs qui la prennent en charge.

## Garder le contexte avec le travail

Lorsque tu ouvres **Ajouter** depuis une tâche, Lotti relie la nouvelle entrée à cette tâche. Les enregistrements, notes, images et relevés de temps restent ainsi réunis sur la page de détail. Utilise une entrée de journal autonome si le contenu n'appartient pas encore à un résultat précis : tu pourras la lier plus tard.

Consulte [Enregistrer de l'audio](./recordings.mdx) pour la capture et la transcription, ou [Travailler avec les tâches](../organize-and-reflect/tasks.mdx) pour la structure des tâches, les illustrations de couverture et les liens entre tâches.
