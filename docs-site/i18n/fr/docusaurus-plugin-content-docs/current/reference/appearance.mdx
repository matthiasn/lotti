# Choisir l’apparence de Lotti

Ouvre **Paramètres → Préférences → Thème** pour contrôler l’aspect de Lotti.
Lotti est livré avec un seul thème soigneusement réglé, décliné en version
claire et en version sombre ; il ne te reste qu’à choisir laquelle des deux
l’application utilise, et à quel moment.

## Sélectionner un mode d’affichage

Le sélecteur affiche trois icônes ; survole-en une ou fais un appui long
dessus pour voir son nom.

- La lune, **Apparence sombre**, utilise toujours la déclinaison sombre.
- L’ordinateur portable — un téléphone sur iOS et Android — correspond à
  **Automatique**, qui suit le réglage clair ou sombre actuel du système
  d’exploitation.
- Le soleil, **Apparence claire**, utilise toujours la déclinaison claire.

Le mode automatique est pratique quand ton appareil change d’apparence selon
un horaire : Lotti suit ce changement sans autre intervention.

Il n’y a pas de bouton Enregistrer : le mode d’affichage est mémorisé dès que
tu le sélectionnes, et il est repris sur tes autres appareils quand la
synchronisation est configurée. Le commutateur clair/sombre du manuel est
indépendant : il change la documentation et choisit automatiquement la
variante de capture d’écran correspondante, mais il ne modifie pas tes
réglages Lotti.
