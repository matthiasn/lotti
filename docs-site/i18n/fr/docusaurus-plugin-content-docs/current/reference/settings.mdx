# Trouver les réglages

Les réglages sont regroupés selon la fonction qu’ils contrôlent. Sur ordinateur,
une arborescence reste affichée avec la page sélectionnée à côté ; sur mobile,
une liste dédiée ouvre une page de réglages à la fois.

Sur ordinateur, choisis **Manuel**, juste au-dessus de **Paramètres**, pour ouvrir
ce guide dans ton navigateur par défaut. Le lien reste disponible lorsque la
barre latérale est repliée.

Le niveau supérieur affiche, dans cet ordre :

- **[Intégration](../getting-started/onboarding.mdx)** pour rejouer le
  parcours d’accueil.
- **Sections** pour activer ou désactiver des parties entières de
  l’application, comme Habitudes ou Projets.
- **Paramètres IA** pour les fournisseurs, modèles, profils et compétences.
- **Agents** pour les modèles d’agents, les instances et la surveillance.
- **Daily OS** pour le profil d’inférence et le message d’accueil du planificateur.
- **Paramètres de synchronisation** pour l’état de connexion et d’activité.
- **Définitions** pour les catégories, les étiquettes, les habitudes, les
  tableaux de bord, les mesurables et le dictionnaire vocal.
- **Préférences** pour [Thème](./appearance.mdx) (modes d’affichage clair,
  sombre et automatique), [Animations](./completion-celebrations.mdx), les
  notifications,
  [Parole](./speech.mdx) et [Raccourcis clavier](./keyboard-shortcuts.mdx).
- **[Paramètres avancés](./advanced-settings.mdx)** pour les flags, la
  journalisation, les actions de maintenance, les diagnostics d’intégration et
  les informations de build.
- **Manuel**, qui ouvre ce manuel dans ton navigateur.

L’ensemble exact peut varier selon les capacités de la plateforme et les fonctionnalités activées.

## Activer et désactiver des sections

Lotti démarre avec peu de choses. Ouvre **Paramètres → Sections** pour
ajouter les parties que tu veux : Daily OS, Projets, Objectifs,
Habitudes, Tableaux de bord, Personnes et Événements. Chaque section
activée obtient sa propre place dans la navigation, dans l’ordre de la
liste.

Désactiver une section la masque, ainsi que son entrée de navigation.
Rien de ce que tu y as enregistré n’est supprimé, et la réactiver te
rend tout à l’identique.

## Gérer les définitions

Ouvre **Paramètres → Définitions** pour gérer les structures qui organisent tes
données. Les catégories définissent les périmètres de planification et de
confidentialité, les étiquettes relient les tâches entre les catégories, les
habitudes définissent les routines récurrentes, les tableaux de bord organisent
les vues de réflexion et les éléments mesurables définissent les nombres que tu
suis dans le temps.
