# Collega un provider AI

Lotti separa una configurazione AI in tre livelli: un **provider** è il
servizio a cui si collega, un **modello** è un modello esposto attraverso quel
servizio e un **profilo di inferenza** indirizza ogni tipo di lavoro a un
modello. Parti dal provider, poi rivedi i modelli e i profili creati attorno a
esso.

## Scegli locale o remoto

- Un provider cloud è di solito la configurazione più rapida e richiede
  comunemente una chiave API. Testo, audio o immagini inviati attraverso di
  esso lasciano il dispositivo.
- Un provider locale può tenere l'inferenza sulla tua macchina o su un endpoint
  locale che controlli, ma il suo servizio deve essere in esecuzione e
  raggiungibile dal dispositivo dove Lotti lo invoca. Un indirizzo LAN può
  comunque spostare un prompt tra i tuoi dispositivi; “locale” significa che
  non viene inviato a un fornitore di modelli ospitato, non che non esista
  nessun passaggio di rete.
- Un URL di base personalizzato può puntare un tipo di provider supportato
  verso un proxy o gateway compatibile. Il tipo di provider controlla comunque
  il comportamento specifico del protocollo.

## Collega un provider

1. Apri **Impostazioni → Impostazioni dell'intelligenza → Fornitori**.
2. Seleziona il pulsante **+**.
3. Scegli un provider supportato.
4. Inserisci nome visualizzato, endpoint e chiave API quando richiesti.
5. Aggiungi i modelli suggeriti che vuoi, poi salva.

Per i provider supportati alla prima esecuzione, Lotti inizializza modelli
utili e uno o più profili di inferenza. La schermata di risultato riassume cosa
è stato creato.

## Ispeziona e mantieni una connessione

Apri la scheda di un provider per ispezionare la credenziale mascherata, l'URL
di base, i modelli salvati e ogni profilo attivo che dipende da quei modelli.
Da qui puoi modificare la connessione, aggiungere un altro modello o rimuovere
il provider.

Cambiare un URL di base o una chiave API influisce su ogni modello collegato a
quel provider. Dopo aver cambiato uno dei due valori, verifica un'azione AI
rappresentativa prima di dare per sana la connessione. Rimuovere un provider
può anche toccare i profili che instradano lavoro attraverso i suoi modelli;
rivedi prima le informazioni sulle dipendenze.

## Rivedi l'instradamento dei profili

Apri [Modelli e profili di inferenza](./models-and-profiles.mdx) per verificare
cosa espone il provider e come Lotti instrada ogni capacità. Le categorie
possono impostare un profilo predefinito per il loro lavoro, mentre le singole
automazioni possono selezionare o sostituire un modello dove il flusso di
lavoro offre quella scelta.

## Il confine della privacy

Prima di inviare testo, audio o immagini sensibili, verifica se l'endpoint
configurato è locale o remoto. Un nome amichevole come “Laboratorio locale di Habitat” non
è il confine di sicurezza — lo sono l'URL di base, il percorso di rete e la
macchina che lo serve. Lotti memorizza il logbook in locale in entrambi i casi;
questa decisione controlla la chiamata di inferenza in sé.

:::warning[Chiavi API]

Tratta le chiavi dei provider come segreti. Non incollarle mai in
documentazione, issue o screenshot.

:::
