# Aggiungi voci e contesto

Lotti usa un unico menu **Aggiungi** per le cose che catturi durante la
giornata. Aprilo dal diario per una voce indipendente, oppure da un'attività
per mantenere la nuova voce allegata a quell'attività.

## Scegli la voce adatta al materiale

| Azione | Usala per |
| --- | --- |
| **Lista di controllo** | Una breve serie di passi concreti dentro l'attività corrente |
| **Compiti** | Un risultato separato che ha bisogno di stato e contesto propri |
| **Registrazione audio** | Una nota vocale che può essere riascoltata o trascritta |
| **Cronometro** | Una sessione di lavoro a tempo collegata al contesto corrente |
| **Inserimento del testo** | Note, decisioni, osservazioni o informazioni incollate |
| **Immagine di importazione** | Un'immagine esistente dal dispositivo |
| **Sceneggiatura** | Un nuovo screenshot del desktop allegato come voce immagine |

Il menu è contestuale. **Lista di controllo** è disponibile quando un'attività
può contenere gli elementi, mentre le azioni specifiche del dispositivo, come
**Sceneggiatura**, compaiono solo dove la piattaforma le supporta.

## Tieni il contesto insieme al lavoro

Quando apri **Aggiungi** da un'attività, Lotti collega la nuova voce a
quell'attività. Così registrazioni, note, immagini e registrazioni del tempo
restano insieme nella pagina di dettaglio dell'attività. Usa una voce di diario
indipendente quando il materiale non appartiene ancora a un risultato
specifico; potrai collegarlo più tardi.

Vedi [Registra audio](./recordings.mdx) per cattura e trascrizione, oppure
[Lavora con le attività](../organize-and-reflect/tasks.mdx) per struttura delle
attività, copertine e collegamenti tra attività.
