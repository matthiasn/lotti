# Aggiungi voci e contesto

Lotti usa un unico menu **Aggiungi** per le cose che catturi durante la
giornata. Aprilo dal diario per una voce indipendente, oppure da un'attività
per mantenere la nuova voce allegata a quell'attività.

## Scegli la voce adatta al materiale

| Azione | Usala per |
| --- | --- |
| **Scrivi una nota** | Note, decisioni, osservazioni o informazioni incollate |
| **Aggiungi una checklist** | Una breve serie di passi concreti dentro l'attività corrente |
| **Registra una nota vocale** | Una nota vocale che può essere riascoltata o trascritta |
| **Aggiungi un'attività** / **Collega una nuova attività** | Un risultato separato che ha bisogno di stato e contesto propri |
| **Aggiungi un evento** | Qualcosa che è successo, con le sue foto e le sue persone |
| **Avvia un timer** | Una sessione di lavoro a tempo collegata alla voce corrente |
| **Importa un'immagine** | Un'immagine esistente dal dispositivo |
| **Cattura uno screenshot** | Un nuovo screenshot del desktop allegato come voce immagine |
| **Incolla un'immagine** | L'immagine che hai negli appunti in quel momento |

Il menu è contestuale. **Aggiungi una checklist** compare solo su
un'attività, e una nuova attività aperta da un'attività viene collegata a essa
(**Collega una nuova attività**). Su un'attività, **Registra tempo**
nella sua barra delle azioni sostituisce **Avvia un timer**.
**Aggiungi un evento** richiede che gli eventi siano attivi,
**Incolla un'immagine** compare solo mentre gli appunti contengono
un'immagine, e **Cattura uno screenshot** solo sui desktop che lo supportano.

## Tieni il contesto insieme al lavoro

Quando apri **Aggiungi** da un'attività, Lotti collega la nuova voce a
quell'attività. Così registrazioni, note, immagini e registrazioni del tempo
restano insieme nella pagina di dettaglio dell'attività. Usa una voce di diario
indipendente quando il materiale non appartiene ancora a un risultato
specifico; potrai collegarlo più tardi.

Vedi [Registra audio](./recordings.mdx) per cattura e trascrizione, oppure
[Lavora con le attività](../organize-and-reflect/tasks.mdx) per struttura delle
attività, copertine e collegamenti tra attività.
