# Scegli l'aspetto di Lotti

Apri **Impostazioni → Tema** per controllare l'aspetto di Lotti. Lotti include
un unico tema curato nei dettagli, disponibile in una resa chiara e in una
scura: devi solo scegliere quale delle due usare, e quando.

## Seleziona una modalità di visualizzazione

Scegli una delle tre modalità:

- **Aspetto scuro** usa sempre la resa scura.
- **Automatico** segue l'impostazione chiara o scura corrente del sistema
  operativo.
- **Aspetto chiaro** usa sempre la resa chiara.

La modalità automatica è utile quando il dispositivo cambia aspetto secondo un
orario: Lotti segue il cambiamento senza altri interventi.

Non c'è alcun pulsante Salva: la modalità di visualizzazione viene memorizzata
appena la selezioni e, se la sincronizzazione è configurata, arriva anche
sugli altri tuoi dispositivi. L'interruttore chiaro/scuro del manuale è
separato: cambia la documentazione e sceglie automaticamente la variante di
schermata corrispondente, ma non modifica le tue impostazioni di Lotti.
