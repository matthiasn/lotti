# Lavora con le scorciatoie da tastiera

Su desktop Lotti espone un catalogo ricercabile di comandi globali e
contestuali. Apri **Impostazioni → Tasti di scelta rapida** per vedere ogni
comando con la combinazione risolta per la tua piattaforma.

## Apri rapidamente la guida delle scorciatoie

Premi **F1** o **Primario + ?** per aprire il riferimento delle scorciatoie
senza lasciare quello che stai facendo. **Primario** significa Comando su
macOS e Control su Windows o Linux.

Tra i comandi globali più utili:

| Azione | Scorciatoia |
| --- | --- |
| Aprire la tavolozza dei comandi | Primario + K |
| Creare una voce di testo | Primario + N |
| Creare un'attività | Primario + T |
| Aprire Attività, Daily OS, Progetti o Abitudini | Primario + 1 / 2 / 3 / 4 |
| Aprire Dashboard, Diario, Eventi o Impostazioni | Primario + 5 / 6 / 7 / 8 |

Le singole pagine aggiungono comandi contestuali come salvare, aggiornare,
cercare o creare. La loro disponibilità può dipendere da cosa ha il focus in
quel momento o dalla presenza di modifiche non salvate.

## Esegui un comando senza lasciare il tuo lavoro

Premi **Primario + K** per aprire la tavolozza dei comandi sopra la pagina
corrente. Combina le azioni globali — creare voci, aprire attività, navigare e
regolare lo zoom — con i comandi forniti dalla pagina attiva.

<ManualScreenshot
  caseId="keyboard-shortcuts/palette"
  alt="La tavolozza dei comandi di Lotti aperta sopra Tasti di scelta rapida, con l'elenco dei comandi disponibili di creazione, navigazione, visualizzazione e modifica"
  caption="Compaiono solo i comandi disponibili nel contesto corrente. La vista Mobile mostra la stessa tavolozza desktop in una finestra stretta; i comandi da tastiera sono una funzione desktop."
/>

Inizia a digitare per restringere l'elenco per nome dell'azione, gruppo o
combinazione di tasti. Usa le frecce su e giù per spostare la selezione,
**Invio** per eseguire il comando ed **Esc** per chiudere la tavolozza.
Poiché la tavolozza è contestuale, un comando come **Salva** compare solo
quando l'editor con il focus può davvero salvare.

## Cerca per azione o per tasto

<ManualScreenshot
  caseId="keyboard-shortcuts/search"

Usa il campo di ricerca quando conosci l'azione o parte della sua combinazione
di tasti. Se una combinazione cambia in una versione successiva di Lotti, fa
fede il catalogo dentro l'app.
