# Scegli uno stile di registrazione

Apri **Impostazioni → Preferenze → Stile di registrazione** per scegliere la
visualizzazione mostrata mentre Lotti registra l'audio. Cambia solo la
presentazione: entrambi gli stili rappresentano lo stesso processo di
registrazione.

## Confronta i due stili

- **Moderno — energia orb** mostra un orb di energia animato che reagisce al
  livello corrente.
- **Analoga — Misuratore di VU** mostra un misuratore VU tradizionale con un
  ago che si muove.

Seleziona una delle due schede per renderla lo stile attivo. Non c'è nessuna
azione Salva o Continua separata.

## Anteprima con la tua voce

Abilita **Prova con la tua voce** per pilotare l'anteprima dal microfono.
Parla alla distanza che prevedi di usare durante la registrazione e osserva
come risponde lo stile visivo selezionato. Disattiva l'opzione quando hai
finito di confrontare gli stili.

L'anteprima ti aiuta a scegliere un linguaggio visivo; non è uno strumento di calibrazione
del guadagno in ingresso o della qualità di registrazione. Vedi [Registra audio](../plan-and-capture/recordings.mdx)
per il flusso di lavoro di registrazione reale.
