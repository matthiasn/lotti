# Trova le impostazioni

Le impostazioni sono raggruppate in base a ciò che controllano. Il desktop usa
un albero persistente con la pagina selezionata accanto; il mobile usa un
elenco essenziale e apre una pagina di impostazioni alla volta.

Scegli **Manuale** nella sezione finale delle Impostazioni per aprire questa
guida nel tuo browser predefinito. Su macOS, **Aiuto → Manuale** offre lo
stesso link. La guida segue la lingua di sistema per impostazione predefinita;
quando serve, scegli una lingua diversa in
**Impostazioni → Impostazioni avanzate → Lingua**.

Le destinazioni più comuni includono:

- **[Aspetto](./appearance.mdx)** per le modalità di visualizzazione chiara,
  scura e automatica.
- **[Stile di registrazione](./recording-style.mdx)** per l'orb di energia o
  il misuratore analogico mostrato durante la registrazione.
- **[Discorso](./speech.mdx)** per la voce on-device, il modello e la velocità
  usati per leggere ad alta voce i riepiloghi delle attività.
- **[Tasti di scelta rapida](./keyboard-shortcuts.mdx)** per il catalogo
  ricercabile dei comandi desktop.
- **[Celebrazioni di completamento](./completion-celebrations.mdx)** per
  animazioni, feedback tattile, stili e il loro playground dal vivo.
- **[Impostazioni avanzate](./advanced-settings.mdx)** per flag delle
  funzionalità, logging, azioni di manutenzione, diagnostica dell'onboarding e
  informazioni sulla build.
- **Categorie** per i confini di pianificazione ed **Etichette** per i tag
  trasversali.
- **Abitazioni** e **Pannelli** per le strutture di riflessione.
- **Impostazioni dell'intelligenza** per provider, modelli, profili e
  competenze.
- **Sistema operativo giornaliero** per il profilo di inferenza del
  pianificatore e il saluto.
- **Impostazioni di sincronizzazione** per la connessione e lo stato di
  attività.

Il set esatto può variare con le capacità della piattaforma e le funzionalità
abilitate.

## Gestisci le definizioni

Apri **Impostazioni → Definizioni** per gestire le strutture che organizzano i
tuoi dati. Le categorie fissano i confini di pianificazione e privacy, le
etichette contrassegnano le attività attraverso le categorie, le abitudini
definiscono le routine ricorrenti, le dashboard dispongono le viste di
riflessione e i misurabili definiscono i numeri che segui nel tempo.
