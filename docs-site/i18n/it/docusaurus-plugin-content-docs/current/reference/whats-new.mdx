# Sfoglia le novità

What's New presenta le note di rilascio dentro Lotti, abbinate alla versione
che stai eseguendo. Può aprirsi da solo dopo un primo avvio o un cambio di
versione idonei, ed è disponibile anche dalla voce **Che cosa è nuovo** nelle
Impostazioni quando la funzionalità è abilitata.

Le note di rilascio sono ordinate dalla più recente. Ogni pagina combina
un'immagine di copertina specifica della release, la versione esatta dell'app e
un breve resoconto delle modifiche visibili all'utente.

## Leggi la release corrente

Il badge di versione identifica la release le cui note sono sullo schermo.
**NUOVO** contrassegna la release più recente del set corrente; non significa
che ogni elemento della pagina sia incompleto o sperimentale.

Il corpo scorre in modo indipendente quando la release è più lunga dell'altezza
disponibile. I link usano il normale gestore dei link di Lotti e, quando
possibile, le immagini vengono precaricate, così passare da una versione
all'altra resta fluido.

Per navigare usa i controlli nel piè di pagina:

- la freccia destra apre la release subito più vecchia;
- la freccia sinistra torna a una release più recente;
- gli indicatori di posizione mostrano dove si trova la pagina corrente nel
  set caricato;
- **Salta!** chiude un set multi-release prima dell'ultima pagina e segna come
  visto l'intero set caricato; e
- **Fatto** compare sulla pagina più vecchia e segna anch'esso l'intero set
  come visto.

Chiudere la finestra trascinandola via o toccando l'area scurita intorno è più
prudente: Lotti segna come viste solo le release che hai davvero raggiunto,
fino alla pagina più lontana visualizzata. Le release che non hai raggiunto
possono quindi ricomparire alla prossima apertura di What's New.

## Rileggi le note già archiviate

Quando non restano release da vedere, aprire What's New mostra lo stato
**You're all caught up**. Scegli **View past releases** per azzerare i
segnalibri locali di lettura e sfogliare di nuovo il set di release
disponibile. Questo cambia solo la cronologia locale delle note di rilascio:
non altera la versione installata dell'app né scarica un'altra build.

What's New non mostra mai note per una release più recente della versione di
Lotti installata. Se il contenuto della release non può essere caricato, l'app
ripiega su uno stato vuoto invece di presentare le note della build sbagliata.

Per il numero di build esatto, la piattaforma, i totali locali delle voci e i
conteggi delle attività, vedi
[A proposito di Lotti](./advanced-settings.mdx#verifica-la-build-e-i-totali-locali).
