# Importa i dati sulla salute

L'importazione della salute è disponibile su iOS e Android. Apri
**Impostazioni → Avanzate → Importo della salute**, scegli una data di inizio e
una di fine, poi seleziona la famiglia di dati che vuoi che Lotti legga
dall'archivio dei dati sanitari del telefono.

Le importazioni disponibili sono:

- **Attività** per i totali di attività;
- **Sonno** per i campioni di sonno;
- **Frequenza cardiaca** per le osservazioni del battito;
- **Pressione sanguigna** per le letture della pressione;
- **Misurazione del corpo** per le letture delle metriche corporee; e
- **Allenamento** per gli allenamenti registrati.

Ogni pulsante importa solo la propria famiglia di dati sull'intervallo di date
mostrato. Cambiare l'intervallo non avvia un'importazione da solo.

Il sistema operativo può chiederti il permesso per i dati sanitari. Lotti può
leggere solo i tipi che concedi. Se una famiglia di dati attesa manca,
controlla i permessi di salute dell'app nelle impostazioni di sistema del
telefono e riprova quell'importazione.

L'importazione della salute non è mostrata sul desktop perché gli archivi di
salute mobili sottostanti non sono disponibili lì. Le osservazioni importate
possono comunque essere viste nelle relative dashboard di Lotti dopo che si
sono sincronizzate su un altro dispositivo.
