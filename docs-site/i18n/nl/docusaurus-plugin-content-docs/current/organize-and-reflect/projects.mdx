# Voer werk uit als projecten

Projecten bevinden zich tussen categorieën en taken. Een categorie zoals **Penguin
Operations** definieert een breed verantwoordelijkheidsgebied; **Project Waddle**
groepeert de concrete taken die nodig zijn om het orbitale pinguïnverblijf voor te
bereiden.

## Vind het project dat je nodig hebt

Zoeken matcht projecttitels, opgeslagen projecttekst en categorienamen. Het
filterbesturingselement beperkt de lijst op projectstatus of categorie. Een filter
blijft inactief totdat je **Toepassen** selecteert.

<ManualScreenshot
  caseId="projects/filters"
  alt="Projectfilterdialoog met status- en categoriebesturing boven de projectlijst van Intergalactic Penguin Logistics"
/>

Projecten blijven na filtering gegroepeerd op categorie. Zo zijn gelijknamige
inspanningen gemakkelijker te onderscheiden en blijft elk operationeel gebied zichtbaar.

## Maak een project

Selecteer de knop **+** in Projecten en voer vervolgens in:

- een verplichte titel;
- een optionele categorie; en
- een optionele streefdatum.

<ManualScreenshot
  caseId="projects/create"
  alt="Formulier voor projectaanmaak voor Vestig het maansardinereservaat in de categorie Penguin Operations"
  caption="Het aanmaakformulier is een onderblad op mobiel en een gecentreerd dialoogvenster op desktop."
/>

Een nieuw project start met de status **Openen**. Als de categorie een
projectagentsjabloon heeft, zet Lotti die agent ook klaar nadat het project is
opgeslagen. Het project werkt normaal wanneer er geen passend sjabloon bestaat.

Gebruik een titel die het resultaat of de blijvende missie beschrijft. “Vestig het
maansardinereservaat” zegt meer dan “Sardines.”

## Projectinstellingen bewerken

De projectinstellingenroute biedt de volledige formuliereditor voor status, titel,
streefdatum, gezondheid, agenttoewijzing, voorgestelde agentwijzigingen en gekoppelde
taken. De acties **Annuleren** en **Opslaan** blijven onderaan vastgezet, zodat
openstaande formulierwijzigingen expliciet zijn.

## Begrijp de projectstatus

| Status | Gebruik deze wanneer |
| --- | --- |
| Openen | Het project bestaat, maar de actieve uitvoering is nog niet gestart. |
| Actief | Het werk is in beweging en hoort thuis in de dagplanning. |
| Toezicht | Er is geen werk gepland, maar het resultaat moet nog geobserveerd worden. |
| In wacht | Het werk is om een bekende reden onderbroken. |
| Voltooid | Het beoogde resultaat is bereikt. |
| Gearchiveerd | Het project blijft bewaard voor de geschiedenis, maar is niet langer operationeel. |

Selecteer de statuspil op de projectdetailpagina om de status te wijzigen. Status-,
categorie- en streefdatumwijzigingen worden onmiddellijk opgeslagen; er is geen aparte
opslaanknop op dit leesgerichte detailoppervlak.

## Lees de projectgezondheid en het bijbehorende verslag

<ManualScreenshot
  caseId="projects/detail"
  alt="Project Waddle-detail met een gezondheidsscore van 82, vijf van de acht voltooide taken, één blocker en een AI-verslag dat twee uur geleden is bijgewerkt"
  caption="Desktop houdt de projectlijst en het detail naast elkaar. Mobiel opent hetzelfde detail als een volledige pagina."
/>

Het gezondheidspaneel vat de huidige beoordeling van de projectagent samen:

- de gezondheidsscore is een compact signaal en geen vervanging voor het onderliggende
  werk;
- de taakvoortgang toont het aantal voltooide en geblokkeerde taken;
- het verslag geeft een actuele samenvatting en kan worden uitgevouwen naar de volledige inhoud; en
- aanbevelingen vestigen de aandacht op concrete vervolgacties.

In Project Waddle zijn een score van 82 en vijf voltooide taken bemoedigend, maar
de gewichtloze visvoeder is nog steeds een lanceringsblocker. Lees de uitleg
voordat je een score als een oordeel behandelt.

Wanneer een projectagent is geconfigureerd, kan het verslagmenu een nieuw verslag
aanvragen of een geplande wakkercyclus annuleren. Zonder agent toont het project nog
steeds zijn taken en eventuele opgeslagen projecttekst.

## Houd projectwerk in taken

<ManualScreenshot
  caseId="projects/tasks"
  alt="Project Waddle-takenpaneel met habitatinspectie, kalibratie van de gewichtloze visvoeder en bevestiging van de sardinevrachtpods, met schattingen en statussen"
/>

Projecttaakrijen tonen van elke taak de titel, korte samenvatting, schatting en huidige
status. Selecteer een rij om de taak zelf te openen. Taakdetails blijven de bron van
waarheid voor beschrijvingen, opnames, checklists, afbeeldingen, tijdregistraties en
omslagafbeeldingen.

Wijs een taak toe aan een project via het projectbesturingselement in de taakkop.
Projecten zijn per categorie ingedeeld, dus geef de taak een categorie voordat je een
project kiest. Een taak behoort tot maximaal één project tegelijk; een ander project
toewijzen verplaatst de koppeling in plaats van deze te dupliceren.

## Projecten, categorieën en taken

Gebruik de drie niveaus bewust:

- **Categorie:** een duurzaam operationeel gebied zoals Penguin Operations.
- **Project:** een resultaat met meerdere taken, zoals Project Waddle.
- **Taak:** een uitvoerbare eenheid, zoals het opnieuw kalibreren van de gewichtloze
  visvoeder.

Maak geen project voor één enkele eenvoudige actie. Gebruik er een wanneer meerdere
taken een gedeelde streefdatum, status, voortgangsoverzicht of operationeel verslag
nodig hebben.
