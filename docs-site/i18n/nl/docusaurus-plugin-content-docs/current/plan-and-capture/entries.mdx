# Voeg invoer en context toe

Lotti gebruikt één **Toevoegen**-menu voor de dingen die je gedurende de dag vastlegt.
Open het vanuit het logboek voor een zelfstandige invoer, of vanuit een taak om de
nieuwe invoer aan die taak gekoppeld te houden.

## Kies de invoer die bij het materiaal past

| Actie | Gebruik deze voor |
| --- | --- |
| **Checklist** | Een korte reeks concrete stappen binnen de huidige taak |
| **Taak** | Een aparte uitkomst die een eigen status en context nodig heeft |
| **Audio-opname** | Een spraaknotitie die kan worden afgespeeld of getranscribeerd |
| **Timer** | Een getimede werksessie gekoppeld aan de huidige context |
| **Tekstinvoer** | Aantekeningen, beslissingen, observaties of geplakte informatie |
| **Afbeelding importeren** | Een bestaande afbeelding van het apparaat |
| **Schermafdruk** | Een nieuwe desktopschermafdruk, toegevoegd als afbeeldingsinvoer |

Het menu is contextueel. **Checklist** is beschikbaar wanneer een taak eigenaar kan
zijn van de items, terwijl apparaatspecifieke acties zoals **Schermafdruk** alleen
verschijnen waar het platform ze ondersteunt.

## Houd de context bij het werk

Wanneer je **Toevoegen** opent vanuit een taak, koppelt Lotti de nieuwe invoer terug
aan die taak. Zo blijven opnames, notities, afbeeldingen en tijdregistraties bij
elkaar op de taakdetailpagina. Gebruik een zelfstandige logboekinvoer als het
materiaal nog niet bij een specifiek resultaat hoort; het kan later worden gekoppeld.

Zie [Audio opnemen](./recordings.mdx) voor vastleggen en transcriptie, of
[Werk met taken](../organize-and-reflect/tasks.mdx) voor taakstructuur,
omslagafbeeldingen en taaklinks.
