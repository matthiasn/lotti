# Voeg invoer en context toe

Lotti gebruikt één **Toevoegen**-menu voor de dingen die je gedurende de dag vastlegt.
Open het vanuit het logboek voor een zelfstandige invoer, of vanuit een taak om de
nieuwe invoer aan die taak gekoppeld te houden.

## Kies de invoer die bij het materiaal past

| Actie | Gebruik deze voor |
| --- | --- |
| **Een notitie schrijven** | Aantekeningen, beslissingen, observaties of geplakte informatie |
| **Een checklist toevoegen** | Een korte reeks concrete stappen binnen de huidige taak |
| **Een spraaknotitie opnemen** | Een spraaknotitie die kan worden afgespeeld of getranscribeerd |
| **Taak toevoegen** / **Nieuwe taak koppelen** | Een aparte uitkomst die een eigen status en context nodig heeft |
| **Evenement toevoegen** | Iets wat er gebeurd is, met eigen foto's en mensen |
| **Timer starten** | Een getimede werksessie gekoppeld aan de huidige invoer |
| **Afbeelding importeren** | Een bestaande afbeelding van het apparaat |
| **Schermafbeelding maken** | Een nieuwe desktopschermafbeelding, toegevoegd als afbeeldingsinvoer |
| **Afbeelding plakken** | De afbeelding die nu op je klembord staat |

Het menu is contextueel. **Een checklist toevoegen** verschijnt alleen bij een taak,
en een nieuwe taak die je vanuit een taak opent, wordt eraan gekoppeld (**Nieuwe taak
koppelen**). Bij een taak vervangt **Tijd registreren** in de actiebalk **Timer starten**.
**Evenement toevoegen** vereist dat evenementen zijn ingeschakeld, **Afbeelding
plakken** verschijnt alleen zolang het klembord een afbeelding bevat, en
**Schermafbeelding maken** alleen op desktops die het ondersteunen.

## Houd de context bij het werk

Wanneer je **Toevoegen** opent vanuit een taak, koppelt Lotti de nieuwe invoer terug
aan die taak. Zo blijven opnames, notities, afbeeldingen en tijdregistraties bij
elkaar op de taakdetailpagina. Gebruik een zelfstandige logboekinvoer als het
materiaal nog niet bij een specifiek resultaat hoort; het kan later worden gekoppeld.
