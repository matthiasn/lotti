# Kies een opnamestijl

Open **Instellingen → Opnamestijl** om de visualisatie te kiezen die wordt getoond
terwijl Lotti audio opneemt. Dit verandert alleen de presentatie; beide stijlen
vertegenwoordigen hetzelfde opnameproces.

## Vergelijk de twee stijlen

- **Moderne energiebol** toont een geanimeerde energie-orb die reageert op het huidige niveau.
- **Absolute** (de analoge stijl) toont een traditionele VU-meter met een bewegende naald.

Selecteer een van beide kaarten om die de actieve stijl te maken. Er is geen aparte
opslaan- of doorgaan-actie.

## Bekijk een voorbeeld met je stem

Schakel **Probeer het met je stem** in om het voorbeeld met de microfoon aan te
sturen. Spreek op de afstand die je tijdens het opnemen verwacht te gebruiken en kijk
hoe de geselecteerde visualisatie reageert. Zet de optie uit wanneer je klaar bent
met het vergelijken van stijlen.

De preview helpt je een beeldtaal te kiezen; het is geen kalibratietool voor
invoerversterking of opnamekwaliteit. Zie [Audio opnemen](../plan-and-capture/recordings.mdx)
voor de daadwerkelijke opnameworkflow.
