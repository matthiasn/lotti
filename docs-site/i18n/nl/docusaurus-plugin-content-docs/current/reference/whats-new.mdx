# Blader door Wat is er nieuw

Wat is er nieuw presenteert releasenotities in Lotti, afgestemd op de versie die je
draait. Het kan automatisch openen na een eerste start of versiewijziging die
daarvoor in aanmerking komt, en het is ook beschikbaar via het item **Wat is er
nieuw?** in Instellingen wanneer die mogelijkheid is ingeschakeld.

Releasenotities staan van nieuw naar oud. Elke pagina combineert een
release-specifieke hero-afbeelding, de exacte app-versie en een kort verslag van de
voor de gebruiker zichtbare wijzigingen.

## Lees de huidige release

De versiebadge identificeert de release waarvan de notities op het scherm staan.
**NIEUW** markeert de nieuwste release in de huidige set; het betekent niet dat elk
item op de pagina onaf of experimenteel is.

De tekst scrolt onafhankelijk wanneer de release langer is dan de beschikbare hoogte.
Links gebruiken de normale Lotti-linkafhandeling en afbeeldingen worden waar mogelijk
vooraf geladen, zodat het wisselen tussen releases soepel blijft.

Gebruik de voettekstknoppen om te navigeren:

- de rechterchevron opent de eerstvolgende oudere release;
- de linkerchevron keert terug naar een nieuwere release;
- de positiemarkeringen tonen waar de huidige pagina zich in de geladen set bevindt;
- **Overslaan** sluit een set met meerdere releases vóór de laatste pagina en
  markeert de hele geladen set als gezien; en
- **Klaar** verschijnt op de oudste pagina en markeert eveneens de hele set als gezien.

De modal sluiten door hem weg te slepen of het gedimde gebied eromheen te selecteren
is conservatiever: Lotti markeert alleen de releases die je daadwerkelijk hebt
bereikt, tot en met de verst bekeken pagina. Releases die je niet hebt bereikt,
kunnen daarom opnieuw verschijnen wanneer Wat is er nieuw de volgende keer opent.

## Bekijk notities die je al hebt weggeklikt opnieuw

Wanneer er geen ongeziene releases meer zijn, toont het openen van Wat is er nieuw
een **You're all caught up!**-status. Kies **View past releases** om de lokale
gezien-markeringen te wissen en opnieuw door de beschikbare releaseset te bladeren.
Dit verandert alleen de lokale releasenotitiegeschiedenis; het wijzigt de
geïnstalleerde app-versie niet en downloadt geen andere build.

Wat is er nieuw toont nooit notities voor een release die nieuwer is dan de
geïnstalleerde Lotti-versie. Als de release-inhoud niet kan worden geladen, valt de
app terug op een lege status in plaats van notities voor de verkeerde build te tonen.

Zie voor het exacte buildnummer, platform, lokale invoertotalen en taakaantallen
[Over Lotti](./advanced-settings.mdx#controleer-de-build-en-lokale-totalen).
