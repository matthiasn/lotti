# Een apparaat toevoegen

Al je apparaten delen één synchronisatieaccount. Een apparaat toevoegen betekent
dat je het de inloggegevens van dat account geeft, dus de stroom draait om twee
controles: een korte **controlecode** die je vergelijkt voordat je verbindt, en
daarna een **emoji-verificatie**.

Ze doen verschillend werk. De controlecode vertelt je dat de twee schermen over
hetzelfde account, dezelfde ruimte en dezelfde server gaan — hij vangt een code
van elders op, de fout die mensen echt maken. Hij wordt alleen uit die kenmerken
afgeleid, niet uit het wachtwoord, dus hij zegt niets over de vraag of de
inloggegevens erin nog geldig zijn, en niets over wie er aan de andere kant zit.
De emoji-verificatie die volgt is de stap die het apparaat authenticeert, en tot
die klaar is, kan het nieuwe apparaat niets lezen.

Je hebt beide apparaten voor je nodig. Begin op een apparaat dat al verbonden
is — welk dan ook, telefoon of desktop. Er is geen „hoofdapparaat”. Is er nog
geen enkel apparaat verbonden, dan kan deze pagina je niet helpen — je
allereerste code komt van de serverkant: zie
[Je eerste apparaat](./first-device.mdx).

## Toon de code op een apparaat dat je al gebruikt

Open **Instellingen → Instellingen synchroniseren → Apparaten** en kies
**Apparaat toevoegen**.

Behandel wat op dit scherm staat als je wachtwoord, want dat is wat het bevat.
Iedereen die de QR-code scant of fotografeert, kan inloggen op je
synchronisatieaccount: je items ontsleutelen kan diegene niet zonder ook met
emoji te zijn geverifieerd vanaf een van je apparaten, maar het account
overnemen wel — inclusief het wachtwoord wijzigen en jou buitensluiten. Toon hem
alleen aan een apparaat dat van jou is, en stuur hem nooit via een chat, een
schermafbeelding of een gedeeld scherm.

**Het paneel sluiten verbergt de code; het trekt hem niet in.** De code bevat
het huidige wachtwoord van je account, dus een foto ervan blijft bruikbaar
zolang dat wachtwoord geldt. Denk je dat iemand hem heeft vastgelegd, behandel
hem dan als een uitgelekt wachtwoord en niet als iets dat inmiddels verlopen is.

**Koppelcode kopiëren** is er bewust voor het geval dat het toetredende apparaat
geen camera heeft — een desktop die bij een desktop komt. Het zet dezelfde
inloggegevens op je klembord, dus plak ze direct op het andere apparaat en
nergens anders. **Koppelcode als tekst tonen** toont dezelfde code om van het
scherm af te lezen.

Houd het paneel open. Onder de code volgt een tijdlijn het nieuwe apparaat van
**Wachten op het nieuwe apparaat…** via **Toegetreden — bevestig de emoji's op
beide schermen** tot **Geverifieerd — klaar voor de overdracht**. Kan het paneel
niet nagaan of het nieuwe apparaat is toegetreden, kies dan **Opnieuw
proberen**.

## Scan hem op het nieuwe apparaat

Installeer Lotti op het nieuwe apparaat, open daar **Instellingen →
Instellingen synchroniseren → Apparaten** en kies **Synchronisatie instellen**.
Op een telefoon gaat de camera meteen open; richt hem op het eerste apparaat. Op
een desktop, of als de camera niet beschikbaar is, kies je **Plak de code in
plaats daarvan** om de gekopieerde code te gebruiken. Een stappenbalk bovenaan —
**Code ophalen**, **Controleren**, **Verbinden** — laat zien waar je bent.

Is dit het eerste apparaat op je account, dan is er nog geen ander apparaat om te
scannen: **Je eerste apparaat instellen?** op hetzelfde scherm leidt naar
**Open de gids voor het eerste apparaat**.

## Controleer of de code klopt voor je verbindt

Het decoderen van de code verbindt nog niets. Eerst verschijnt **Vergelijk
voordat je verbindt**: een overzicht van waar je je bij gaat aansluiten, met de
controlecode voorop. Beide apparaten leiden deze code onafhankelijk af uit het
account, de ruimte en de server. Ze wisselen hem nooit uit — daarom loont het om
hem te vergelijken.

Bekijk de controlecode hier en die op het eerste apparaat. **Ze moeten identiek
zijn.** Het sync-account en de synchronisatieserver onder de code zijn context,
niets om te vergelijken — ze verschijnen niet op het andere apparaat. Klopt
alles, kies dan **De codes komen overeen — verbinden**.

Verschillen ze, kies dan **Ze komen niet overeen**. Lotti waarschuwt dat deze
code niet van jouw apparaat komt en verbindt niet; haal een verse code op je eigen
apparaat. Een code die je hebt afgewezen, wordt herkend als je hem opnieuw scant.

## Rond de twee stappen daarna af

Verbinden laat het apparaat toetreden tot het account. Lezen kan het daarmee nog
niet.

  alt="Lotti-synchronisatie-instelling die laat zien dat dit apparaat verbonden is, met de stappen Bevestig de emoji's en Ontvang je instellingen nog open"
  caption="Verbonden is de makkelijke helft. De kaart noemt wat nog ontbreekt en zegt duidelijk dat dit apparaat tot de emoji overeenkomen alleen versleutelde tekst ziet."
/>

1. **Bevestig de emoji's.** Beide apparaten tonen zeven emoji. Controleer dat ze
   overeenkomen en bevestig op elk apparaat. Tot dan ontvangt het nieuwe
   apparaat versleutelde tekst die het niet kan lezen — sleutels worden alleen
   gedeeld met apparaten die je hebt geverifieerd. Verschijnen er geen emoji,
   kies dan **Opnieuw controleren**, of start de verificatie vanuit
   **Apparaten**. Zie
   [Controleer het nieuwe apparaat](./sync.mdx#controleer-het-nieuwe-apparaat).
2. **Ontvang je instellingen.** Terug op het eerste apparaat ontgrendelt het nog
   open paneel Apparaat toevoegen twee overdrachten zodra de emoji overeenkomen:
   **Instellingen versturen** levert je categorieën, gewoonten, dashboards en
   AI-instellingen, en **Berichtgeschiedenis verzenden** levert de items die zijn
   geschreven voordat dit apparaat toetrad. Stuur beide — de geschiedenis is de
   reden dat een nieuw apparaat niet meer leeg oogt.

Laat beide apps open tot de eerste synchronisatie klaar is. Heb je het paneel
gesloten, dan biedt de pagina **Apparaten** op het eerste apparaat dezelfde twee
overdrachten aan zolang hij meldt dat het nieuwe apparaat net is toegetreden.
Open anders daar **Instellingen → Instellingen synchroniseren → Onderhoud**,
kies **Meetbare gegevens synchroniseren, dashboards, gewoonten, categorieën,
AI-instellingen** en daarna **Berichtgeschiedenis**.

## Als er iets misgaat

- **De controlecodes verschillen.** Verbind niet. Het paneel opnieuw openen helpt
  op zich niet: hetzelfde account, dezelfde ruimte en dezelfde server leveren
  altijd dezelfde code op, dus een verschil betekent dat de twee schermen niet
  dezelfde koppeling beschrijven.
- **De code laat zich niet decoderen.** Kopieer hem opnieuw op het eerste
  apparaat in plaats van te bewerken wat je hebt geplakt; de gecodeerde waarde
  is niet bedoeld om met de hand te corrigeren. Meldt de app een
  versieverschil, dan draaien de twee apparaten verschillende Lotti-versies en
  moeten ze allebei worden bijgewerkt.
- **De code werkt niet meer.** Een code logt niet meer in zodra het
  accountwachtwoord is gewijzigd. Kies **Deze code opnieuw proberen** als de
  verbinding wegviel, of **Nieuwe code invoeren** en haal een verse op je andere
  apparaat.
- **Het nieuwe apparaat is verbonden maar blijft leeg.** Dat is vóór de
  verificatie de verwachte toestand. Rond de emoji-vergelijking af, verstuur
  instellingen en berichtgeschiedenis en bekijk daarna bij
  [Synchroniseer apparaten](./sync.mdx) de status van de uitbox en de backfill.

Ga verder met [Synchroniseer apparaten](./sync.mdx) voor de dagelijkse status,
de gezondheid van de levering en hersteltools.
