# Executa habilidades de IA contextuais

As habilidades de IA são ações com nome, com instruções e requisitos de
entrada. O Lotti filtra o menu **Gerar…** de acordo com a entidade atual, para
que uma tarefa não ofereça uma ação de transcrição só para áudio e uma imagem
não ofereça uma ação que exige uma gravação.

## Executa uma habilidade

1. Abre uma tarefa ou uma entrada de diário suportada.
2. Seleciona a ação de assistente com contorno no cabeçalho da entrada. Isso
   abre **Gerar…**.
3. Lê a descrição da habilidade e seleciona a ação que queres.
4. Se o Lotti oferecer um seletor de modelo ou de modo de raciocínio, confirma
   a predefinição ou escolhe uma substituição pontual.
5. Continua a trabalhar enquanto a inferência corre; quando termina, o
   resultado é anexado à tarefa ou entrada relevante.

O Lotti traz seis tipos de habilidades, e o menu oferece as que a entrada
suporta:

| Habilidade | Aparece em |
| --- | --- |
| **Transcrição** | entradas de áudio |
| **Resumo da gravação** | entradas de áudio — resume a gravação no contexto a que pertence e corrige termos do dicionário mal ouvidos |
| **Análise de imagem** | imagens |
| **Geração de imagem** | entradas de áudio e de texto associadas a uma tarefa |
| **Geração de prompt** | tudo o que tenha texto — notas, áudio, imagens, tarefas |
| **Geração de prompt de imagem** | tudo o que tenha texto, como acima |

Se faltar uma ação que esperavas, o tipo de entrada não suporta essa
habilidade — ou nenhum perfil lhe atribui um modelo.

Algumas habilidades precisam de uma tarefa associada, porque leem o contexto
mais amplo da tarefa ou escrevem o resultado de volta nessa tarefa. Se uma
ação não aparecer, verifica primeiro o tipo da entrada e a ligação à tarefa;
depois, verifica se o perfil de inferência ativo tem um modelo para a
capacidade necessária.

## As substituições de modelo são temporárias

Quando uma habilidade oferece um seletor de modelo, essa escolha aplica-se à
invocação atual. Não reescreve às escondidas a predefinição da categoria nem o
perfil de inferência. Para mudares o encaminhamento normal, edita o perfil em
[Modelos e perfis de inferência](./models-and-profiles.mdx).

## Trata o resultado gerado como um rascunho

Revê os prompts, resumos, transcrições, análises de imagem e imagens gerados
antes de confiares neles. O contexto da tarefa pode estar incompleto, os
provedores podem devolver resultados errados, e até um modelo capaz pode
interpretar mal uma emergência de sardinhas muito séria.
