# Revê o uso e o impacto da IA

Abre **Configurações → Configurações de IA → Uso e impacto** para perceberes
como estão a ser usados os modelos de nuvem configurados. A mesma análise
também está acessível pela rota do painel de impacto da IA.

## Lê os cartões de resumo

Os cartões no topo resumem o período selecionado:

- **Custo** estima os gastos com o provedor.
- **Energia** estima a eletricidade atribuível à inferência medida na nuvem.
- **CO₂e** exprime a estimativa das emissões associadas.
- **Tokens** conta os tokens de modelo processados.
- **Solicitações** conta as chamadas de inferência.

O indicador de comparação usa o período equivalente anterior quando está
disponível. Um aumento percentual é contexto, não um problema automático: uma
semana de revisão de lançamento não deve ser comparada às cegas com uma semana
parada na colónia.

Energia, CO₂e e custo são medidos apenas para modelos de nuvem. A inferência
local pode gastar bastante energia do dispositivo sem aparecer nestas
estimativas de nuvem; por isso, esta página não é um medidor de energia
completo para o sistema inteiro.

## Altera a análise

Usa o controlo de período e os botões de seta para avançar ou recuar no tempo,
ou salta para **Este mês** e **Este ano**. Depois, escolhe **Ambos**,
**Por categoria** ou **Por modelo**. Dentro de um gráfico, alterna entre
valores por dia, totais acumulados e percentagem, quando disponível.

As vistas por categoria respondem a «que área de trabalho fez subir o uso?»;
as vistas por modelo respondem a «que modelo configurado fez subir o uso?».
Usa ambas antes de alterar um perfil: um modelo caro pode justificar-se para
uma categoria especializada e ser um desperdício como predefinição geral.

## Age perante um resultado surpreendente

Se o uso subir inesperadamente:

1. restringe o período ao primeiro dia afetado;
2. compara categorias e modelos;
3. revê a automação e a simultaneidade dos agentes;
4. inspeciona o perfil de inferência atribuído à categoria afetada; e
5. verifica a faturação no provedor antes de tratares a estimativa do Lotti
   como uma fatura.

Para alterar a rota responsável pelas chamadas futuras, volta a
[Modelos e perfis de inferência](./models-and-profiles.mdx).
