# Cria a tua primeira tarefa

Uma tarefa é a casa de um resultado, da sua lista de verificação e das notas,
gravações, imagens ou registos de tempo que explicam o trabalho.

## Começa pelo caminho mais rápido

Se ainda estiveres na integração, diz o resultado em voz alta ou escolhe
**Preferes escrever?**. Escolhe a área a que a tarefa pertence; o Lotti usa
essa categoria para manter a tarefa visível nas vistas certas e para
selecionar a automação configurada.

antes de sair da integração. Abre o cartão para continuares no espaço de
trabalho normal das tarefas.

## Cria uma tarefa a partir da lista de tarefas

1. Abre **Tarefas**.
2. Seleciona **Adicionar uma tarefa**. Num telemóvel, está no lançador de
   navegação.
3. Escreve um título orientado para o resultado.
4. Escolhe uma categoria quando houver uma que se aplique claramente.
5. Guarda a tarefa.

No computador, o espaço de trabalho das tarefas mantém a lista e a tarefa
selecionada lado a lado. No telemóvel, selecionar uma tarefa abre o detalhe em
ecrã inteiro. Em ambos os esquemas, a arte de capa das tarefas e o contexto da
categoria tornam uma lista cheia mais fácil de percorrer.

“Publicar o manual V1” é mais útil do que “Documentação”, porque o título diz
como é o trabalho quando está pronto.

## Adiciona contexto útil

Abre a tarefa e usa a ação de adicionar para anexar uma nota, uma gravação,
uma imagem ou outra entrada. Guarda o material junto da tarefa quando isso te
puder ajudar — a ti ou a um assistente de IA — a perceber a próxima ação mais
tarde.

## Torna-a acionável

Adiciona uma pequena lista de verificação com passos concretos. Se um provedor
de IA e as habilidades relevantes estiverem configurados, o Lotti também pode
transformar uma gravação ou um contexto escrito em sugestões para a lista de
verificação. Revê as alterações propostas antes de as aplicares.

## Decide quando importa

- Define uma data limite quando houver um prazo real.
- Define a prioridade para exprimir urgência.
- Traz a tarefa para um check-in do Daily OS quando ela fizer parte do plano
  de hoje.

Continua com a [gestão de tarefas](../organize-and-reflect/tasks.mdx) para a
prioridade, a filtragem e os fluxos de trabalho assistidos por voz.
