# Organiza com categorias

Uma categoria é a principal casa estrutural de uma entrada. Usa uma quando um
conjunto de trabalho precisa das suas próprias regras de planeamento, de um
limite de privacidade, de uma identidade visual ou de contexto de IA. No
espaço de trabalho de demonstração, **Operações com pinguins**, **Controle da
Missão**, **Diplomacia dos Peixes** e **Manutenção Humana** separam áreas
realmente diferentes da expedição.

## Cria uma categoria

<TutorialVideo
  scenario="category_setup"
  title="Configura uma categoria"
  caption="Passo a passo narrado: criar uma categoria, definir as opções de favorito e privacidade e configurar as predefinições de IA."
/>

1. Abre **Configurações → Definições → Categorias**.
2. Seleciona **Criar categoria**.
3. Introduz um nome, uma cor e um ícone distintos.
4. Cria-a e depois volta a abrir a categoria para configurares o seu
   comportamento.

A criação começa de propósito pelos campos de identificação. As opções de
planeamento, privacidade, idioma e automação ficam no editor completo, depois
de a categoria existir.

## Configura o comportamento da categoria

<ManualScreenshot
  caseId="categories/detail"
  alt="Editor da categoria Operações com pinguins com o nome, a identidade de voo roxa e as opções de favorito, privado, ativo e planeamento do dia"
/>

O editor controla mais do que a aparência:

- **Favorito** torna uma categoria importante mais fácil de reconhecer e
  selecionar.
- **Privado** oculta o conteúdo dela, a não ser que as entradas privadas
  estejam a ser mostradas. É um limite de visibilidade, não uma encriptação
  separada para a própria categoria.
- **Ativo** controla se a categoria pode ser selecionada para novas entradas.
  Desativá-la preserva os dados existentes.
- **Planeamento do dia** deixa a categoria participar no planeamento do Daily
  OS.
- **Idioma** define o idioma predefinido para novas tarefas na categoria.

Usa o **Planeamento do dia** com critério. Ativá-lo em todas as categorias
alarga o contexto do planeador e torna o ritual diário mais ruidoso.

## Adiciona contexto de automação próprio da categoria

Em **Padrões de IA**, uma categoria pode fornecer predefinições para novas
tarefas: um perfil de inferência e um modelo de agente. São predefinições, não
bloqueios permanentes; as escolhas ao nível da tarefa podem mudar mais tarde.

- **Inferência automática** deixa o Lotti transcrever áudio novo, analisar
  imagens novas e resumir pull requests nesta categoria sem teres de pedir.
  Aparece assim que o perfil da categoria consegue fazer uma destas coisas e
  continua visível enquanto estiver ligada.
- Com um modelo de agente escolhido, **Ativar o assistente automaticamente**
  decide se os novos agentes de tarefa se atualizam sozinhos quando uma tarefa
  muda, e **Ritmo de atualização** define com que frequência o fazem.

**Conhecimento da categoria** é o que todos os prompts de IA para tarefas
desta categoria devem saber — o que ela é, onde está o código, convenções,
armadilhas. Entra no prompt palavra por palavra, até 4000 caracteres.

O vocabulário de reconhecimento de fala já não fica numa categoria. O
[dicionário de voz](./speech-dictionary.mdx) guarda cada termo uma só vez e
pode limitá-lo às categorias a que pertence; os termos que as categorias
tinham foram transferidos para lá.

Quando corriges à mão os títulos de listas de verificação geradas, o Lotti
pode guardar os exemplos de antes e depois para futuras sugestões de IA. Revê
os exemplos aqui e remove qualquer correção que não deva orientar resultados
futuros.

## Categorias versus etiquetas

Usa uma categoria como a casa principal do trabalho e uma
[etiqueta](./labels.mdx) para uma propriedade transversal. **Operações com
pinguins** é uma categoria; **Habitat crítico** é uma etiqueta que também
se pode aplicar ao trabalho do Controle da Missão.

Mantém o sistema de categorias pequeno o suficiente para que escolher uma
seja óbvio. Adiciona uma nova categoria quando ela muda o planeamento, a
filtragem, a privacidade ou a automação — não só porque apareceu um
substantivo novo.
