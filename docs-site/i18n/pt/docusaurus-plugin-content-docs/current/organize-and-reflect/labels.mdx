# Marca o trabalho com etiquetas

As etiquetas acrescentam uma segunda camada flexível de organização. Uma tarefa
tem uma única categoria principal, mas pode levar várias etiquetas para
iniciativas, urgência, estados de espera ou qualquer outra propriedade que
atravesse os limites das categorias.

O espaço de trabalho Intergalactic Penguin Logistics usa etiquetas de forma
deliberada:

- **Project Waddle** liga o trabalho de lançamento entre Operações com
  pinguins, Controle da Missão e Diplomacia dos Peixes.
- **Habitat crítico** identifica o trabalho que tem de terminar antes de a
  expedição entrar no habitat orbital.
- **Aguardando Controle da Missão** regista um estado de bloqueio real.
- **Mercado de sardinha sensível** mantém identificável o trabalho privado de
  negociação.

## Cria e edita uma etiqueta

1. Abre **Configurações → Definições → Etiquetas**.
2. Seleciona **Criar etiqueta**.
3. Acrescenta um nome conciso e uma descrição opcional.
4. Escolhe uma cor que continue fácil de distinguir ao lado das outras
   etiquetas.
5. Decide se a etiqueta é privada e que categorias a podem usar.
6. Guarda.

Vale a pena escrever descrições quando uma etiqueta pode ser interpretada de
mais de uma maneira. Dão o significado operacional sem obrigar a pôr essa
explicação em cada título de tarefa.

**Categorias aplicáveis** limitam onde a etiqueta pode ser selecionada. O
Project Waddle está disponível nas três áreas da expedição envolvidas no
lançamento, enquanto uma etiqueta especializada pode ficar limitada a uma só
categoria. Assim, os seletores mantêm-se relevantes, em vez de mostrarem todas
as etiquetas em todo o lado.

## Aplica etiquetas às tarefas

Abre uma tarefa e usa o controlo de etiquetas para adicionar ou remover
etiquetas. As etiquetas funcionam em conjunto com os filtros de estado,
prioridade e categoria da tarefa, por isso podes fazer perguntas focadas como
«mostrar o trabalho aberto P1 crítico para o habitat» sem inventar uma nova
categoria para essa vista temporária.

## Deixa um agente de tarefa sugerir etiquetas

Quando um agente de tarefa configurado tem contexto suficiente sobre a tarefa,
pode sugerir etiquetas adequadas juntamente com outras alterações à tarefa. O
Lotti só disponibiliza etiquetas ativas válidas para a categoria da tarefa e
rejeita sugestões eliminadas, fora de âmbito, duplicadas ou de baixa
confiança. O agente nunca tem caminho livre para criar marcadores arbitrários
a partir de um prompt.

Revê uma etiqueta sugerida pelo agente na área de alterações propostas da
tarefa, tal como revês uma alteração à checklist, à data ou ao estado.
Confirma-a quando a etiqueta melhorar a filtragem futura; rejeita-a quando não
melhorar. Assim, a organização visível da tarefa continua sob o teu controlo,
em vez de tratares um palpite do modelo como fonte de verdade.

Remover uma etiqueta de uma tarefa é tratado como uma rejeição intencional
quando as sugestões automáticas de etiquetas estão ativas. O Lotti regista
essa escolha para que a mesma sugestão não volte a ser aplicada logo a seguir
sem um novo motivo.

## Mantém as etiquetas úteis

- Prefere etiquetas que mudem uma decisão, um filtro ou uma revisão.
- Reutiliza uma etiqueta estável em vez de criares variantes de grafia.
- Verifica as contagens de uso antes de eliminar ou fundir etiquetas.
- Usa a privacidade quando o próprio nome da etiqueta revelar um contexto
  confidencial.
- Retira as etiquetas que já não descrevem trabalho em curso.

Se algo for a casa principal e duradoura do trabalho, transforma-o numa
[categoria](./categories.mdx).
