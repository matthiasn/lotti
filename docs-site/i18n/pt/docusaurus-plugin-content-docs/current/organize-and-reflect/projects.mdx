# Conduz o trabalho como projetos

Os projetos ficam entre as categorias e as tarefas. Uma categoria como
**Operações com pinguins** define uma área ampla de responsabilidade; o **Project
Waddle** agrupa as tarefas concretas necessárias para preparar o habitat
orbital dos pinguins.

## Encontra o projeto de que precisas

A pesquisa procura nos títulos dos projetos, no texto guardado do projeto e
nos nomes das categorias. Por baixo do campo de pesquisa, **Atuais** oculta os
projetos concluídos e arquivados; **Todos** volta a mostrá-los.
**Ordenar projetos** ordena a lista por **Precisa de atenção**, **Data-alvo**,
**Atualizados recentemente** ou **Nome**.

O botão de filtro restringe a lista por **Estado** ou **Categoria**. Dois
interruptores acrescentam mais: **Só resumos desatualizados** mantém os
projetos cujo resumo do agente está atrasado, e **Mostrar perfil de
inferência** marca cada projeto com agente com o nome do seu perfil de
inferência. Um filtro fica inativo até selecionares **Aplicar**.

<ManualScreenshot

Os projetos continuam agrupados por categoria depois da filtragem. Isso torna
mais fácil distinguir esforços com nomes parecidos e mantém visível cada área
operacional. Cada cabeçalho de categoria pode ser recolhido, e o botão de mapa
abre **Explorar categoria** — os projetos da categoria como um bairro que se
pode percorrer.

## Cria um projeto

Seleciona o botão **+** em Projetos e indica:

- um título obrigatório;
- uma categoria opcional; e
- uma data prevista opcional.

<ManualScreenshot
  caseId="projects/create"
  alt="Formulário de criação de projeto para Estabelecer a reserva lunar de sardinhas na categoria Operações com pinguins"
  caption="O formulário de criação é um painel inferior no telemóvel e uma caixa de diálogo centrada no computador."
/>

Um projeto novo começa como **Aberto**. Se a categoria tiver um modelo de
agente de projeto, o Lotti também cria esse agente depois de o projeto ser
guardado. O projeto continua a funcionar normalmente quando não existe um
modelo correspondente.

Usa um título que descreva o resultado ou a missão duradoura. “Estabelecer a
reserva lunar de sardinhas” diz mais do que “Sardinhas”.

## Edita as definições do projeto

Escolhe **Editar projeto** nos detalhes de um projeto para abrir o editor de
formulário completo dentro do espaço de trabalho de Projetos. Abrange o título,
a descrição, a categoria, o estado e a data prevista. A saúde, as ações do
agente, as alterações propostas e as tarefas ligadas ficam nos detalhes do
projeto, pensados para leitura. **Cancelar** e **Guardar** ficam logo abaixo do
formulário, e qualquer uma das ações regressa a esse projeto.

## Percebe o estado do projeto

| Estado | Usa-o quando |
| --- | --- |
| Aberto | O projeto existe, mas a execução ainda não começou. |
| Ativo | O trabalho está em andamento e pertence ao planeamento do dia. |
| Monitorização | Não há trabalho agendado, mas o resultado ainda precisa de ser observado. |
| Em espera | O trabalho está em pausa por um motivo conhecido. |
| Concluído | O resultado pretendido foi alcançado. |
| Arquivado | O projeto fica como histórico, mas já não está operacional. |

Seleciona a pílula de estado na página de detalhes do projeto para o alterar.
As alterações de estado, de categoria e de data prevista são guardadas de
imediato; não há um botão de guardar separado nesta superfície de detalhes
pensada para leitura.

## Lê a saúde do projeto e o relatório

  caption="No computador, a lista de projetos e os detalhes ficam lado a lado. No telemóvel, os mesmos detalhes abrem como uma página inteira."
/>

O cartão **Resumo de IA** junta a avaliação e o relatório:

- **Saúde do projeto** resume a avaliação do agente, com a justificação e a
  confiança quando existem, e quantas tarefas estão bloqueadas;
- o relatório dá um resumo atual, e **Ler mais** expande-o até ao conteúdo
  completo; e
- os próximos passos e as alterações propostas chamam a atenção para ações
  concretas.

No Project Waddle, uma avaliação No caminho certo é animadora, mas o
alimentador de peixe em gravidade zero continua a bloquear o lançamento. Lê a
justificação antes de tratares a faixa como um veredicto.

O próprio cartão mantém apenas **Detalhes do agente**, e
**Atualizar agora** enquanto o resumo estiver desatualizado. A configuração do
modelo, as atualizações automáticas e a frequência com que o agente se
atualiza estão nos internos do agente. Sem agente, o cartão oferece
**Atribuir agente** e os detalhes continuam a mostrar as tarefas e a descrição
do projeto.

**Explorar projeto**, ao lado do menu do projeto, abre o projeto como um
bairro que se pode percorrer, com um edifício por cada tarefa.

## Adiciona notas, gravações e imagens a um projeto

Uma barra ao longo do fundo da página do projeto acrescenta coisas diretamente
ao projeto: **Gravar uma nota de voz**, escrever uma nota, importar uma imagem,
ou o mais para o menu **Adicionar** com o resto. Num ecrã estreito, os botões
de nota e de imagem dão lugar ao mais. Tudo o que adicionares aí fica ligado ao
projeto, aparece na sua cronologia e é lido pelo seu agente.

## Mantém o trabalho do projeto nas tarefas

<ManualScreenshot
  caseId="projects/tasks"
  alt="Painel de tarefas do Project Waddle com a inspeção do habitat, a calibração do alimentador de peixe em gravidade zero e a confirmação das cápsulas de carga de sardinhas, com estimativas e estados"
/>

As linhas de tarefas do projeto mostram o título de cada tarefa, um resumo
curto, a estimativa e o estado atual. Seleciona uma linha para abrir a própria
tarefa. Os detalhes da tarefa continuam a ser a fonte da verdade para
descrições, gravações, listas de verificação, imagens, registos de tempo e
arte de capa.

Atribui uma tarefa a um projeto através do controlo de projeto no cabeçalho
da tarefa. Os projetos estão limitados por categoria, por isso dá uma
categoria à tarefa antes de escolheres um projeto. O agente da tarefa também o
pode propor: menciona o projeto nas notas da tarefa ou numa gravação, e o
agente sugere mover a tarefa para ele — ou, quando a categoria não tem nenhum
projeto com esse nome, criar o projeto com a tarefa lá dentro. Nada muda até
confirmares. Uma tarefa pertence no máximo a um projeto de cada vez; atribuir
outro projeto move a ligação em vez de a duplicar.

A categoria de um projeto não pode mudar enquanto este tiver tarefas ligadas
ou um agente de projeto ativo. Isto evita que a pertença e as permissões do
agente derivem silenciosamente para outras categorias.

## Projetos, categorias e tarefas

Usa os três níveis de forma deliberada:

- **Categoria:** uma área operacional duradoura, como Operações com pinguins.
- **Projeto:** um resultado com várias tarefas, como o Project Waddle.
- **Tarefa:** uma unidade executável, como recalibrar o alimentador de peixe
  em gravidade zero.

Evita criar um projeto para uma única ação simples. Usa um quando várias
tarefas precisarem de partilhar uma data prevista, um estado, um consolidado
de progresso ou um relatório operacional.
