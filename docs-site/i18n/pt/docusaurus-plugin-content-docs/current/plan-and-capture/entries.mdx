# Adiciona entradas e contexto

O Lotti usa um único menu **Adicionar** para as coisas que registas ao longo
do dia. Abre-o a partir do diário para uma entrada avulsa, ou a partir de uma
tarefa para manteres a nova entrada associada a essa tarefa.

## Escolhe a entrada que corresponde ao material

| Ação | Usa-a para |
| --- | --- |
| **Escrever uma nota** | Notas, decisões, observações ou informação colada |
| **Adicionar uma lista de verificação** | Um pequeno conjunto de passos concretos dentro da tarefa atual |
| **Gravar uma nota de voz** | Uma nota de voz que pode ser reproduzida ou transcrita |
| **Adicionar uma tarefa** / **Vincular uma nova tarefa** | Um resultado separado que precisa de estado e contexto próprios |
| **Adicionar um evento** | Algo que aconteceu, com as suas próprias fotos e pessoas |
| **Iniciar um temporizador** | Uma sessão de trabalho cronometrada associada à entrada atual |
| **Importar uma imagem** | Uma imagem existente do dispositivo |
| **Fazer uma captura de ecrã** | Uma nova captura de ecrã do computador anexada como entrada de imagem |
| **Colar uma imagem** | A imagem que tens neste momento na área de transferência |

O menu é contextual. **Adicionar uma lista de verificação** só aparece numa
tarefa, e uma nova tarefa aberta a partir de uma tarefa fica associada a ela
(**Vincular uma nova tarefa**). Numa tarefa, **Registar tempo** na barra de
ações substitui **Iniciar um temporizador**. **Adicionar um evento** exige que
os eventos estejam ligados, **Colar uma imagem** só aparece enquanto a área de
transferência contém uma imagem, e **Fazer uma captura de ecrã** só nos
computadores que o suportam.

## Mantém o contexto junto do trabalho

Quando abres **Adicionar** a partir de uma tarefa, o Lotti associa a nova
entrada a essa tarefa. Assim, gravações, notas, imagens e registos de tempo
ficam juntos na página de detalhe da tarefa. Usa uma entrada avulsa no diário
quando o material ainda não pertence a um resultado concreto; podes
associá-la mais tarde.

Consulta [Gravar áudio](./recordings.mdx) para a gravação e a transcrição, ou
[Trabalhar com tarefas](../organize-and-reflect/tasks.mdx) para a estrutura
das tarefas, a arte de capa e as ligações entre tarefas.
