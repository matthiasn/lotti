# Escolhe a aparência do Lotti

Abre **Configurações → Preferências → Tema** para controlar a aparência do
Lotti. O Lotti traz um único tema cuidadosamente afinado, com uma versão clara
e uma escura — só tens de escolher qual das duas a aplicação usa, e quando.

## Seleciona um modo de visualização

O seletor mostra três ícones; passa o cursor por cima de um ou mantém-no
premido para veres o nome.

- A lua, **Aparência escura**, usa sempre a versão escura.
- O portátil — um telemóvel no iOS e no Android — é **Automático**, que segue a
  definição atual de claro ou escuro do sistema operativo.
- O sol, **Aparência clara**, usa sempre a versão clara.

O modo automático é útil quando o dispositivo muda de aparência segundo um
horário: o Lotti acompanha essa mudança sem mais nenhuma ação tua.

Não há botão Guardar: o modo de visualização fica gravado assim que o
selecionas e, com a sincronização configurada, chega também aos teus outros
dispositivos. O seletor de claro e escuro do próprio manual é independente:
muda a documentação e escolhe automaticamente a variante correspondente da
captura de ecrã, mas não altera as tuas definições do Lotti.
