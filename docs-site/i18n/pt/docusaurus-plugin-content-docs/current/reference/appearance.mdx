# Escolha a aparência do Lotti

Abra **Configurações → Preferências → Tema** para controlar a aparência do
Lotti. O Lotti traz um único tema cuidadosamente ajustado, com uma versão clara
e uma escura — você só precisa escolher qual das duas o aplicativo usa, e
quando.

## Selecione um modo de exibição

Escolha um dos três modos:

- **Aparência escura** sempre usa a versão escura.
- **Automático** segue a configuração atual de claro ou escuro do sistema
  operacional.
- **Aparência clara** sempre usa a versão clara.

O modo automático é útil quando o dispositivo muda de aparência conforme uma
programação: o Lotti acompanha essa mudança sem nenhuma outra ação.

Não há botão Salvar: o modo de exibição é gravado assim que você o seleciona
e, com a sincronização configurada, chega também aos seus outros
dispositivos. O seletor de claro e escuro do próprio manual é independente:
ele muda a documentação e escolhe automaticamente a variante correspondente
da captura de tela, mas não altera suas configurações do Lotti.
