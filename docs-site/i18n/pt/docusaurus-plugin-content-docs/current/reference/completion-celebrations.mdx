# Personaliza as celebrações de conclusão

Abre **Configurações → Preferências → Animações** para decidires como o Lotti
reage quando terminas uma tarefa, cumpres um hábito ou marcas um item de uma
lista de verificação.

## Escolhe onde aparecem as celebrações

- **Animações de celebração** é o interruptor principal dos efeitos visuais.
- **Hábitos**, **Itens da lista de verificação** e **Tarefas** controlam de
  forma independente os respetivos efeitos visuais de conclusão.
- **Háptica de conclusão** controla a breve resposta física e continua
  disponível mesmo quando as animações estão desativadas.

Desativar uma animação nunca anula a conclusão em si. Se o sistema operativo
pedir movimento reduzido, o Lotti suprime os efeitos e guarda os estilos
selecionados para mais tarde.

## Atribui um estilo a cada tipo de conclusão

<ManualScreenshot
  caseId="celebrations/styles"
  alt="Seletor de estilo de celebração do Lotti com Tarefas selecionado e as opções Faíscas, Fogos de artifício, Confete, Brasas, Bolhas, Aleatório e Combine dois"
  caption="Tarefas, hábitos e itens da lista de verificação podem usar estilos diferentes. Seleciona um cartão para o pré-visualizares e aplicares."
/>

Para cada tipo de conclusão, escolhe **Faíscas**, **Fogos de artifício**,
**Confete**, **Brasas** ou **Bolhas**. Escolhe **Aleatório** para teres um
único estilo novo a cada conclusão, ou **Combine dois** para sobrepores dois
estilos escolhidos ao acaso.

Usa **Experimenta** para pré-visualizar a seleção atual sem alterar dados
reais de tarefas ou hábitos.

## Ajusta um estilo individual

Seleciona a ação de personalizar num estilo fixo para abrires o respetivo
playground em ecrã inteiro.

<ManualScreenshot
  caseId="celebrations/playground"
  alt="Playground de celebração Faíscas do Lotti com pré-visualização ao vivo de uma tarefa e controlos agrupados de forma, movimento e aspeto"
  caption="As alterações ficam guardadas e aplicam-se em todo o lado de imediato. Reproduz a amostra depois de cada ajuste."
/>

Os controlos disponíveis dependem do efeito e estão agrupados em **Forma**,
**Movimento** e **Aspeto**. Ajusta os controlos deslizantes e usa a amostra
destacada ou **Repetir** para veres o resultado. **Redefinir para o padrão**
repõe o estilo integrado; a confirmação oferece **Desfazer** caso tenhas
reposto sem querer.

A personalização é global para esse estilo. Não fica ligada à tarefa de
exemplo mostrada no playground nem a nenhuma tarefa real específica.
