# Trabalha com atalhos de teclado

No computador, o Lotti oferece um catálogo pesquisável de comandos globais e
contextuais. Abre **Configurações → Preferências → Atalhos de teclado** para
veres cada comando com a combinação resolvida para a tua plataforma.

## Abre rapidamente a ajuda dos atalhos

Prime **F1** ou **Primário + ?** para abrires a referência de atalhos sem
saíres do que estás a fazer. **Primário** significa Command no macOS e Control
no Windows ou no Linux.

Entre os comandos globais mais úteis estão:

| Ação | Atalho |
| --- | --- |
| Abrir a paleta de comandos | Primário + K |
| Perguntar ao acompanhante | Primário + L |
| Criar uma entrada de texto | Primário + N |
| Criar uma tarefa | Primário + T |
| Abrir o histórico de itens abertos | Command + Y no macOS, Control + H no Windows ou no Linux |
| Abrir Tarefas, DailyOS, Projetos ou Hábitos | Primário + 1 / 2 / 3 / 4 |
| Abrir Análises, Diário de bordo, Eventos ou Configurações | Primário + 5 / 6 / 7 / 8 |

As páginas individuais acrescentam comandos contextuais, como guardar,
atualizar, pesquisar ou criar. A sua disponibilidade pode depender do que está
em foco no momento ou de haver alterações por guardar.

## Executa um comando sem saíres do teu trabalho

Prime **Primário + K** para abrires a paleta de comandos sobre a página atual.
Ela combina ações globais da aplicação — criar entradas, abrir tarefas, navegar
e aplicar zoom — com comandos fornecidos pela página ativa. O campo de
pesquisa também encontra tarefas, entradas, projetos, eventos e pessoas pelo
título.

Começa a escrever para restringires a lista por nome de ação, grupo ou
combinação de teclas. Os títulos correspondentes aparecem a seguir aos
comandos, em **Ir para**; quando nenhum título contém todas as palavras que
escreveste, aparecem antes os mais próximos em **Títulos semelhantes**. Usa as
setas para cima e para baixo para mover o destaque, **Enter** para executar o
comando e **Escape** para fechar a paleta. Como a paleta é contextual, um
comando como **Guardar** só aparece quando o editor em foco pode guardar
naquele momento.

## Pesquisa por ação ou tecla

<ManualScreenshot
  caseId="keyboard-shortcuts/search"
  alt="Catálogo de atalhos de teclado do Lotti filtrado com uma pesquisa"
  caption="Pesquisa o catálogo em vez de o decorares. Os resultados atualizam-se à medida que escreves."
/>

Usa o campo de pesquisa quando souberes a ação ou parte da combinação de
teclas. O catálogo dentro da aplicação é a referência definitiva caso um
atalho mude numa versão posterior do Lotti.
