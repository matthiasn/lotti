# Escolhe um estilo de gravação

Abre **Configurações → Preferências → Estilo de gravação** para escolheres a
visualização mostrada enquanto o Lotti grava áudio. Isto altera apenas a
apresentação; os dois estilos representam o mesmo processo de gravação.

## Compara os dois estilos

- **Moderno** mostra um orbe de energia animado que reage ao nível atual.
- **Analógico** mostra um medidor VU tradicional com uma agulha em movimento.

Seleciona um dos cartões para o tornares o estilo ativo. Não há uma ação
separada de Guardar ou Continuar.

## Pré-visualiza com a tua voz

Ativa **Experimenta com a tua voz** para alimentar a pré-visualização com o
microfone. Fala à distância a que pretendes ficar durante a gravação e
observa como responde o visual selecionado. Desativa a opção quando acabares
de comparar os estilos.

A pré-visualização ajuda-te a escolher uma linguagem visual; não é uma
ferramenta de calibração do ganho de entrada nem da qualidade de gravação.
Consulta [Gravar áudio](../plan-and-capture/recordings.mdx) para conheceres o
fluxo real de gravação.
