# Encontra as definições

As definições estão agrupadas pela capacidade que controlam. No computador há
uma árvore permanente com a página selecionada ao lado; no telemóvel há uma
lista focada que abre uma página de definições de cada vez.

Escolhe **Manual** na última secção das Configurações para abrires este guia
no teu navegador predefinido. No macOS, **Ajuda → Manual** dá acesso à mesma
ligação. Por omissão, o guia segue o idioma do teu sistema; escolhe outro
idioma em **Configurações → Configurações avançadas → Idioma** quando for
preciso.

O nível de topo lista, por esta ordem:

- **[Integração](../getting-started/onboarding.mdx)** para voltares a ver o
  fluxo de boas-vindas.
- **Secções** para ligar e desligar partes inteiras da aplicação, como Hábitos
  ou Projetos.
- **Configurações de IA** para provedores, modelos, perfis e habilidades.
- **Agentes** para modelos de agente, instâncias e monitorização.
- **Daily OS** para o perfil de inferência e a saudação do planeador.
- **Configurações de sincronização** para o estado da ligação e da atividade.
- **Definições** para categorias, etiquetas, hábitos, painéis, mensuráveis e o
  dicionário de voz.
- **Preferências** para [Tema](./appearance.mdx) (modos de apresentação claro,
  escuro e automático), [Animações](./completion-celebrations.mdx),
  notificações, [Estilo de gravação](./recording-style.mdx),
  [Fala](./speech.mdx) e [Atalhos de teclado](./keyboard-shortcuts.mdx).
- **[Configurações avançadas](./advanced-settings.mdx)** para sinalizadores de
  funcionalidades, registo, ações de manutenção, diagnósticos da integração e
  informações da compilação.
- **Manual**, que abre este manual no teu navegador.

O conjunto exato pode variar consoante as capacidades da plataforma e as
funcionalidades ativadas.

## Liga e desliga secções

O Lotti começa pequeno. Abre **Configurações → Secções** para adicionares as
partes que quiseres: Daily OS, Projetos, Metas, Hábitos, Painéis, Pessoas e
Eventos. Cada secção que ligas ganha o seu próprio lugar na navegação, pela
ordem que a lista mostra.

Desligar uma secção oculta-a, junto com a respetiva entrada de navegação. Nada
do que lá registaste é eliminado, e ao voltares a ligá-la tudo fica como
estava.

## Gere as definições

Abre **Configurações → Definições** para gerires as estruturas que organizam
os teus dados. As categorias definem limites de planeamento e privacidade, as
etiquetas marcam tarefas entre categorias, os hábitos definem rotinas
recorrentes, os painéis organizam vistas de reflexão e os mensuráveis definem
os números que acompanhas ao longo do tempo.
