# Navega pelas Novidades

As Novidades apresentam notas de lançamento dentro do Lotti, correspondentes à
versão que estás a executar. Podem abrir automaticamente depois de um primeiro
arranque elegível ou de uma mudança de versão, e também estão disponíveis na
entrada **Novidades** das Configurações quando essa funcionalidade está
ativada.

As notas de versão estão ordenadas da mais recente para a mais antiga. Cada
página junta uma imagem de destaque própria do lançamento, a versão exata da
aplicação e um breve relato das mudanças visíveis para o utilizador.

## Lê a versão atual

O emblema de versão identifica o lançamento cujas notas estão no ecrã.
**NOVO** marca o lançamento mais recente do conjunto atual; não significa que
todos os itens da página estejam inacabados ou sejam experimentais.

O corpo desloca-se de forma independente quando o lançamento é maior do que a
altura disponível. Os links usam o tratamento de links normal do Lotti, e as
imagens são pré-carregadas quando disponíveis, para que a navegação entre
versões continue fluida.

## Percorre o histórico de lançamentos

Usa os controlos do rodapé para navegar:

- a seta para a direita abre a versão mais antiga seguinte;
- a seta para a esquerda volta a uma versão mais recente;
- os marcadores de posição mostram onde está a página atual no conjunto
  carregado;
- **Saltar** fecha um conjunto de vários lançamentos antes da última página e
  marca todo o conjunto carregado como visto; e
- **Concluído** aparece na página mais antiga e também marca todo o conjunto
  como visto.

Fechar a janela arrastando-a para fora ou tocando na área escurecida à volta é
mais conservador: o Lotti marca apenas os lançamentos a que chegaste de facto,
até à página mais distante que viste. Os lançamentos a que não chegaste podem,
por isso, aparecer da próxima vez que abrires as Novidades.

## Revê notas que já dispensaste

Quando não resta nenhum lançamento por ver, abrir as Novidades mostra o estado
**You're all caught up!** (este ecrã ainda não está traduzido). Escolhe
**View past releases** para limpar os marcadores locais de visto e voltar a
percorrer o conjunto de versões disponível. Isto altera apenas o histórico
local das notas de lançamento; não altera a versão instalada da aplicação nem
transfere outra compilação.

As Novidades nunca mostram notas de uma versão mais recente do que a versão
instalada do Lotti. Se o conteúdo da versão não puder ser carregado, a
aplicação recorre a um estado vazio em vez de apresentar notas da compilação
errada.

Para o número exato da compilação, a plataforma, os totais locais de entradas
e as contagens de tarefas, consulta
[Sobre Lotti](./advanced-settings.mdx#verifica-a-compilação-e-os-totais-locais).
