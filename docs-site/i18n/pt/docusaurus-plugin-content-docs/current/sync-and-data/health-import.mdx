# Importar dados de saúde

A importação de saúde está disponível no iOS e no Android. Abre
**Configurações → Configurações avançadas → Importação de Saúde**, escolhe uma
data de início e uma de fim e seleciona a família de dados que queres que o
Lotti leia do armazenamento de dados de saúde do telemóvel.

As importações disponíveis são:

- **Atividade** para os totais de atividade;
- **Sono** para as amostras de sono;
- **Frequência cardíaca** para as observações de pulsação;
- **Pressão arterial** para as leituras de pressão arterial;
- **Medidas corporais** para as leituras de métricas corporais; e
- **Treinos** para os treinos registados.

Cada linha importa só a sua própria família de dados no intervalo de datas
mostrado e, quando termina, indica por baixo do nome o que aconteceu: quantas
amostras chegaram, que não havia nenhuma, que o acesso foi negado ou que a
importação falhou. **Importar tudo** executa cada linha à vez. Os atalhos
**Últimos 7 / 30 / 90 dias** definem as duas datas de uma só vez; mudar o
intervalo não inicia, por si só, uma importação.

## Quando uma linha não traz nada

O teu sistema operativo pede autorização para os dados de saúde da primeira
vez que o Lotti lê uma família, e o Lotti só consegue ler os tipos que
autorizares. Pergunta **uma vez por família de dados** — a pressão arterial é
um único pedido que cobre as leituras sistólica e diastólica — e depois não
volta a perguntar por iniciativa própria. Tocar numa linha repete a
importação e pede apenas as autorizações ainda por decidir; um tipo a que já
respondeste não gera nenhum pedido novo, porque o sistema não o apresenta uma
segunda vez.

Uma linha que não leu nada e nunca trouxe uma única amostra diz **Sem dados —
verifique o acesso do Lotti no seu app de saúde**, e aparece um botão **Abrir
configurações** por baixo da lista. É um convite a verificar, não um
veredicto: a Apple não diz de propósito a uma aplicação se ela pode ler um
tipo, por isso o Lotti não consegue distinguir “não tens leituras deste tipo”
de “desligaste este acesso”. Se o desligaste, volta a ligá-lo nas próprias
definições de saúde — no iPhone em **Definições → Saúde → Acesso a dados e
dispositivos → Lotti**, no Android no Health Connect. É o único caminho de
volta; o Lotti não consegue voltar a mostrar o pedido por si. Depois, toca na
linha para importar.

A importação de saúde não aparece no computador porque os armazenamentos de
saúde móveis subjacentes não estão disponíveis lá. As observações importadas
podem na mesma ser vistas nos painéis relevantes do Lotti depois de
sincronizadas com outro dispositivo.
