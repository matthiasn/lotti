# Direcționați munca prin modele și profiluri

Un furnizor îi spune lui Lotti unde să se conecteze. Un model înregistrează ID-ul unui model de furnizor și capabilitățile lui. Un profil de inferență atribuie apoi acele modele tipurilor de muncă pe care le înțelege Lotti. Astfel, întrebarea „ce model se ocupă de audio?” nu mai apare în fiecare sarcină și regulă de automatizare.

## Revizuiți modelele salvate

Deschideți **Setări → Setări AI → Modele**. Modelele formează o singură listă. Deasupra ei, câte un cip de filtru pentru fiecare furnizor și cipurile **Text**, **Viziune**, **Audio** și **Raționament** o restrâng, iar câmpul de căutare găsește furnizori, modele și profiluri după nume.

<ManualScreenshot caseId="ai/models" alt="Pagina Modele din Lotti, cu controalele Setărilor AI în partea de sus, cipuri de filtrare după furnizor și capabilitate și o listă de modele Project Waddle marcate Gândire sau Recunoaștere de imagini" caption="Spațiul Project Waddle combină modele cloud și locale, păstrând explicite capabilitățile fiecărui model." />

În partea de sus a Setărilor AI se află trei controale:

- **Activări simultane ale agenților** limitează câți agenți diferiți pot rula inferență simultan.
- **Ritmul actualizărilor** stabilește cât de des se actualizează singuri agenții de sarcină atunci când nici sarcina, nici categoria ei nu îl stabilesc. **Cel mult o dată pe oră** actualizează totuși imediat după o înregistrare, un cronometru oprit sau o sarcină marcată ca finalizată.
- **Profil de inferență implicit** este rezerva pentru agenții fără o rută de inferență configurată pe acest dispozitiv.

O valoare mai mare pentru **Activări simultane ale agenților** poate îmbunătăți debitul, dar crește și cererile simultane către furnizor, precum și încărcarea dispozitivului local. Păstrați o valoare prudentă dacă furnizorul are limite stricte de rată sau serverul local de modele are memorie limitată.

## Adăugați sau editați un model

Selectați un card de model sau folosiți **+** pentru a adăuga unul. Definiția unui model include conexiunea furnizorului, un nume afișat și o descriere opțională, ID-ul exact al modelului la furnizor, limita maximă de tokenuri pentru completare, modalitățile de intrare și ieșire, precum și marcaje de capabilitate, de exemplu raționament sau apelare de funcții.

<ManualScreenshot caseId="ai/model-editor" alt="Editorul de model Lotti pentru Waddle Command 70B, cu furnizor, ID de model, limită de completare, modalități și capabilitate de raționament" caption="Metadatele de capabilitate contează: Lotti le folosește pentru a decide ce modele sunt eligibile pentru fiecare slot de profil și selector punctual." />

Folosiți identificatorul exact așteptat de furnizor. Numele afișat este doar pentru oameni; schimbarea lui nu schimbă ce rulează furnizorul. Nu declarați suport pentru imagini, audio, instrumente sau raționament decât dacă modelul și punctul final îl oferă cu adevărat.

## Construiți un profil de inferență

Deschideți **Setări → Setări AI → Profiluri de inferență**. Fiecare profil este o politică reutilizabilă de rutare. Prezentarea arată ce model deservește fiecare slot configurat.

<ManualScreenshot caseId="ai/profiles" alt="Profilurile de inferență Lotti pentru Project Waddle Command, Habitat Local-First și Fish Diplomacy, cu modelele direcționate" caption="Profilurile pot optimiza limite diferite: un profil cloud larg, unul local numai pentru desktop sau un profil specialist de raționament." />

Editați un profil pentru a atribui modele capabilităților utilizate:

- **Gândire** este modelul general de text obligatoriu.
- **Model de chat** răspunde în conversații; folosește modelul de gândire când nu este setat.
- **Gândire (nivel înalt)** poate gestiona munca ce solicită explicit o cale de raționament mai capabilă.
- **Recunoaștere de imagini** analizează imagini.
- **Transcriere** convertește audio în text.
- **Postprocesare audio** corectează o transcriere pe baza dicționarului vocal și scrie rezumatul înregistrării; folosește modelul de gândire când nu este setat.
- **Generare de imagini** creează ilustrații pentru sarcini și alte imagini generate. Ruta încorporată actuală folosește un furnizor la distanță; alegeți furnizorul și referințele trimise cu aceeași grijă ca pentru orice altă inferență cloud.
- **Citire cu voce tare** este modelul vocal cloud care citește cu voce tare rezumatele și răspunsurile; folosește vocea de pe dispozitiv când nu este setat.

Sub **Competențe automatizate**, la finalul formularului, activați competențele — transcrierea și analiza imaginilor — care rulează singure cu acest profil. Fiecare folosește modelul slotului său, așa că activarea necesită ca slotul respectiv să fie completat.

<ManualScreenshot caseId="ai/profile-editor" alt="Editorul profilului Project Waddle Command, cu nume, descriere și sloturi de model pentru Gândire, Model de chat, Gândire (nivel înalt), Recunoaștere de imagini, Transcriere, Postprocesare audio și Generare de imagini" caption="Un profil direcționează fiecare modalitate Project Waddle fără repetarea alegerilor de modele între sarcini." />

**Doar desktop** ascunde un profil pe platformele mobile, util când depinde de un model accesibil doar de pe o stație de lucru. Fixarea pe dispozitiv este pentru procesarea automată a materialului audio sincronizat: fixați numai când dispozitivul ales expune furnizorii necesari profilului. Fără dispozitiv fixat, materialul audio sincronizat nu este transcris automat de acel profil.

## Alegeți un model fără a memora ID-uri

Selectoarele de modele încep cu furnizorul și arată numai modelele salvate compatibile. Selectorul unui slot de profil, de exemplu, nu va oferi un model numai audio pentru raționament textual.

<ManualScreenshot caseId="ai/model-picker" alt="Fereastra Lotti Alegeți un model, cu furnizorii OpenRouter, Ollama și Google Gemini peste editorul profilului Project Waddle" caption="Alegeți mai întâi furnizorul; Lotti restrânge apoi pagina următoare la modelele eligibile din acea conexiune." />

## Stabiliți o valoare implicită pentru categorie

O categorie poate alege un profil de inferență implicit în **Setări → Definiții → Categorii**. Un agent rulează pe profilul ales pentru el; fără unul, urmează la fiecare rulare profilul categoriei sale, așa că schimbarea profilului categoriei își mută și agenții. Fără niciunul dintre ele, revine la **Profil de inferență implicit** din partea de sus a Setărilor AI. Alegeți profilul al cărui amestec de confidențialitate și capabilități se potrivește categoriei, nu numai după viteză.

<ManualScreenshot caseId="ai/profile-picker" alt="Editorul categoriei Operațiuni cu pinguini, cu o fereastră care oferă profilurile Project Waddle Command, Habitat Local-First și Fish Diplomacy" caption="O pictogramă de monitor marchează un profil Doar desktop înainte ca acesta să fie selectat ca valoare implicită pentru categorie." />

## Ruta veche de profil

Ruta veche independentă **Profiluri de inferență** rămâne disponibilă pentru compatibilitate și editează aceleași înregistrări de profil stocate. Ea expune ID-uri interne de modele și oferă mai puțin context despre dependențe decât Setările AI, așa că preferați pagina actuală **Setări AI → Profiluri de inferență** pentru întreținerea obișnuită.
