# Adăugați înregistrări și context

Lotti folosește un singur meniu **Adăugați** pentru lucrurile pe care le capturați în timpul zilei. Deschideți-l din jurnal pentru o înregistrare independentă sau dintr-o sarcină pentru a păstra noua înregistrare atașată acelei sarcini.

## Alegeți înregistrarea potrivită materialului

| Acțiune | O folosiți pentru |
| --- | --- |
| **Scrieți o notă** | Note, decizii, observații sau informații lipite |
| **Adăugați o listă de verificare** | Un set scurt de pași concreți în sarcina curentă |
| **Înregistrați o notă vocală** | O notă vocală care poate fi redată sau transcrisă |
| **Adăugați o sarcină** / **Legați o sarcină nouă** | Un rezultat separat care are nevoie de propria stare și propriul context |
| **Adăugați un eveniment** | Ceva ce s-a întâmplat, cu propriile fotografii și persoane |
| **Porniți un cronometru** | O sesiune de lucru cronometrată, legată de înregistrarea curentă |
| **Importați o imagine** | O imagine existentă pe dispozitiv |
| **Realizați o captură de ecran** | O nouă captură de ecran desktop atașată ca înregistrare imagine |
| **Lipiți o imagine** | Imaginea aflată în prezent în clipboard |

Meniul este contextual. **Adăugați o listă de verificare** apare numai pe o sarcină, iar o sarcină nouă deschisă dintr-o sarcină este legată de aceasta (**Legați o sarcină nouă**). Pe o sarcină, **Înregistrați timpul** din bara sa de acțiuni înlocuiește **Porniți un cronometru**. **Adăugați un eveniment** necesită activarea evenimentelor, **Lipiți o imagine** apare numai cât timp clipboardul conține o imagine, iar **Realizați o captură de ecran** numai pe desktopurile care o acceptă.

## Păstrați contextul cu munca

Când deschideți **Adăugați** dintr-o sarcină, Lotti leagă noua înregistrare de acea sarcină. Astfel, înregistrările, notele, imaginile și timpul rămân împreună pe pagina de detalii a sarcinii. Folosiți o înregistrare de jurnal independentă atunci când materialul nu aparține încă unui anumit rezultat; o puteți lega mai târziu.

Consultați [Înregistrați audio](./recordings.mdx) pentru capturare și transcriere sau [Lucrați cu sarcini](../organize-and-reflect/tasks.mdx) pentru structura sarcinilor, coperți și legături între sarcini.
