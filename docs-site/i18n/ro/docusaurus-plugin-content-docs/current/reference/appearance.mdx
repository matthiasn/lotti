# Alegeți aspectul Lotti

Deschideți **Setări → Preferințe → Tematică** pentru a controla felul în care
arată Lotti. Lotti include o singură temă atent calibrată, cu o variantă
luminoasă și una întunecată — rămâne doar să alegeți pe care dintre ele o
folosește aplicația și când.

## Selectați un mod de afișare

Alegeți unul dintre cele trei moduri:

- **Aspect întunecat** folosește întotdeauna varianta întunecată.
- **Automat** urmează setarea luminoasă sau întunecată curentă a sistemului de
  operare.
- **Aspect luminos** folosește întotdeauna varianta luminoasă.

Modul Automat este util când dispozitivul își schimbă aspectul după un
program: Lotti urmează schimbarea fără altă intervenție.

Nu există buton Salvați: modul de afișare se păstrează imediat ce îl
selectați și, cu sincronizarea configurată, ajunge și pe celelalte
dispozitive ale dvs. Comutatorul propriu de lumină și întuneric al manualului
este separat: schimbă documentația și alege automat varianta corespunzătoare
de captură de ecran, dar nu modifică setările dvs. Lotti.
