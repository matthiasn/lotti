# Kom ihåg meningsfulla händelser

Evenemang ger meningsfulla ögonblick en egen plats i Lotti. Använd ett
evenemang för en lansering, resa, fest, konferens eller ett annat ögonblick du
vill återvända till. Använd uppgifter för förberedelserna och uppföljningen
runt omkring.

Evenemang är för närvarande en valfri funktion. Öppna **Inställningar → Sektioner** och slå på **Evenemang**.
Destinationen **Evenemang** visas sedan i sidofältet på skrivbordet och i
navigeringsstartaren på mobilen.

## Bläddra och filtrera dina evenemang

Översikten är fotodriven så att ett evenemang känns igen innan du läser dess
titel. Det närmaste framtida evenemanget visas i **Kommande**-hjälten.
Tidigare evenemang grupperas efter år, nyaste först.

Använd **Sök evenemang** för att hitta ett evenemang via dess text.
**Filtrera evenemang**, knappen bredvid sökfältet, öppnar ett kategorifilter:
välj en eller flera kategorier — eller **Otilldelat** — och tillämpa dem för
att begränsa hela arkivet. Filtreringen tillämpas på den lagrade
evenemangssamlingen, inte bara på de kort som just nu syns på skärmen. Varje
kort visar sin kategori, så att du med en blick kan skilja
**Penguin-operationer** från **Fiskdiplomati**.

Lotti laddar ett långt arkiv i sidor och renderar bara närliggande rader, så
hundratals fotorika evenemang förblir praktiska utan att varje omslag laddas
på en gång.

## Skapa ett evenemang

Välj **Nytt evenemang**. Ett nytt evenemang öppnas på sin detaljsida, där du
kan lägga till titel, kategori, datum och tid, status, omslagsfoto och
stödjande poster.

Välj en titel som namnger ögonblicket snarare än dess förberedelser. Till
exempel är **Project Waddle-lanseringsgalan** evenemanget; **Kalibrera om
fiskmataren med nollgravitation** är en kopplad uppgift.

Hjälten håller evenemangets identitet och huvudkontroller samlade:

- välj titeln för att redigera den;
- välj kategori- eller statuspillret för att ändra det;
- välj språkpillret för att välja det språk som evenemangets AI-skrivna
  återblick och förslag hålls på;
- välj datum och tid för att boka om evenemanget;
- välj en stjärna för att ändra betyget på ett avslutat evenemang; och
- öppna överflödesmenyn för att byta omslag eller ta bort evenemanget.

Ändringar sparas via detaljsidan; det finns inget separat formulär att öppna
igen. Ett betyg visas efter att ett evenemang har avslutats, eller när
evenemanget redan har ett betyg.

Under hjälten håller evenemangets agent ett **AI-sammanfattning**-kort —
samma kort som en uppgifts agent använder. Det visar återblickens korta
version med **Läs mer** för resten, **Agentdetaljer**, när den
senast uppdaterades och **Uppdatera nu**. Nedanför listar **Föreslagna
förändringar** vad agenten föreslår, till exempel någon som var där eller en
anteckning att lägga till; godkänn eller avvisa varje förslag, eller använd
**Bekräfta allt**. Ett evenemang utan agent visar i stället sin egen
anteckning, med **Tilldela agent** för att ge det en.

## Ange vem som var där

Sektionen **Personer** visar ett chip per person som är länkad till
evenemanget; välj ett chip för att öppna personens sida. **Redigera personer**
— **Lägg till personer** så länge ingen är länkad ännu — öppnar **Vilka var
där?** för att ändra listan.

## Bygg ett fotografiskt minne

Sektionen **Foton** samlar varje bild som är länkad till evenemanget i
tidsordning. Välj en miniatyr för att öppna helskärmsvisaren, och svep sedan
mellan foton eller nyp för att zooma. En stor samling begränsas till en
kompakt förhandsvisning; den sista rutan visar hur många fler foton som
finns.

Omslaget är ett av evenemangets länkade foton. Tills du väljer ett visar
Lotti det senaste länkade fotot, och rubriken erbjuder **Välj omslag**, så att
standardvalet aldrig tas för ett val. Öppna vilket foto som helst i helskärm
och tryck på **Välj omslag** för att göra det till omslag; det foto som redan
är omslaget visar **Omslag** där, och galleriet markerar det. **Byt omslag** i
överflödesmenyn öppnar samma väljare, där du också kan lägga till ett nytt
foto.

## Följ tidslinjen och relaterat arbete

  caption="Foton, anteckningar, inspelningar och uppföljningsuppgifter förblir kopplade till evenemanget utan att själva evenemanget blir en uppgift."

Tidslinjen sorterar länkade poster från äldsta till nyaste. Den kan innehålla:

- foton och deras bildtexter;
- anteckningar;
- ljudposter och röstanteckningar; och
- tidsposter, visade som start, slut och förfluten tid.

Välj ett tidslinjeobjekt för att öppna dess källpost. Allt du lägger till i
evenemanget kommer från listen längs sidans nederkant: **Lägg till en uppgift**
skapar en förberedelse- eller uppföljningsuppgift som redan är länkad till
evenemanget och öppnar den, inspelningsknappen fångar en röstanteckning för
det, och plusset öppnar menyn **Lägg till** för en anteckning, ett foto, en
ljudpost eller en annan stödd post — alla automatiskt länkade till evenemanget.

Sektionen **Uppgifter** visas så snart den första uppgiften är länkad och
listar evenemangets förberedelser och uppföljning. Välj en uppgift för att
öppna den. På skrivbordet förblir uppgifterna synliga i en högerspalt medan du
läser evenemanget; på mobilen följer de tidslinjen i samma rullning.

## Evenemang eller uppgift?

Använd den här distinktionen när du avgör var något hör hemma:

| Använd ett evenemang för... | Använd en uppgift för... |
| --- | --- |
| Ett ögonblick med datum, foton, återblick och minnesvärde | En handling med status, uppskattning, checklista eller arbetssession |
| Project Waddle-lanseringsgalan | Kalibrera om fiskmataren med nollgravitation |
| Europa-sardinframtidstoppmötet | Bekräfta de interplanetära sardinlastkapslarna |

Länka ihop de två när arbetet stödjer ögonblicket. Det håller evenemanget
roligt att återvända till medan dess operativa arbete förblir genomförbart.
