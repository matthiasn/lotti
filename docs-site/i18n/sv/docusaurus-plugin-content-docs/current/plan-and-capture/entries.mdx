# Lägg till poster och kontext

Lotti använder en **Lägg till**-meny för det du fångar under dagen. Öppna den
från dagboken för en fristående post, eller från en uppgift för att hålla den
nya posten fäst vid den uppgiften.

## Välj den post som matchar materialet

| Åtgärd | Använd den för |
| --- | --- |
| **Checklista** | En kort uppsättning konkreta steg i den aktuella uppgiften |
| **Uppgift** | Ett separat resultat som behöver sin egen status och kontext |
| **Ljudinspelning** | En röstanteckning som kan spelas upp eller transkriberas |
| **Lägg till timer** | En tidsatt arbetssession kopplad till den aktuella kontexten |
| **Textinmatning** | Anteckningar, beslut, observationer eller inklistrad information |
| **Importera bild** | En befintlig bild från enheten |
| **Skärmdump** | En ny skrivbordsskärmdump bifogad som bildpost |

Menyn är kontextuell. **Checklista** finns tillgänglig när en uppgift kan äga
punkterna, medan enhetsspecifika åtgärder som **Skärmdump** bara visas där
plattformen stöder dem.

## Behåll kontexten hos arbetet

När du öppnar **Lägg till** från en uppgift länkar Lotti den nya posten
tillbaka till den uppgiften. Det håller ihop inspelningar, anteckningar,
bilder och tidsposter på uppgiftens detaljsida. Använd en fristående
dagbokspost när materialet ännu inte hör till ett specifikt resultat; den
kan länkas senare.

Se [Spela in ljud](./recordings.mdx) för inspelning och transkribering, eller
[Arbeta med uppgifter](../organize-and-reflect/tasks.mdx) för uppgiftsstruktur,
omslagskonst och uppgiftslänkar.
