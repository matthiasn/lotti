# Välj Lottis utseende

Öppna **Inställningar → Preferenser → Tematisering** för att styra hur Lotti ser
ut. Lotti levereras med ett enda omsorgsfullt avstämt tema i ett ljust och ett
mörkt utförande — du behöver bara välja vilket av de två appen använder, och
när.

## Välj ett visningsläge

Omkopplaren visar tre ikoner; håll pekaren över en av dem eller tryck länge
för att se dess namn.

- Månen, **Mörkt utseende**, använder alltid det mörka utförandet.
- Den bärbara datorn – en telefon på iOS och Android – är **Automatisk**, som
  följer operativsystemets aktuella ljusa eller mörka inställning.
- Solen, **Ljust utseende**, använder alltid det ljusa utförandet.

Automatiskt läge är praktiskt när din enhet byter utseende enligt ett schema:
Lotti följer bytet utan att du behöver göra något mer.

Det finns ingen Spara-knapp: visningsläget sparas så snart du väljer det, och
med synkronisering uppsatt når det även dina andra enheter. Manualens egen
ljus/mörk-omkopplare är fristående: den ändrar dokumentationen och väljer
automatiskt den matchande skärmbildsvarianten, men ändrar inte dina
Lotti-inställningar.
