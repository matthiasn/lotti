# Arbeta med tangentbordsgenvägar

Lotti på skrivbordet erbjuder en sökbar katalog av appövergripande och
kontextuella kommandon. Öppna **Inställningar → Tangentbordsgenvägar** för
att se varje kommando med bindningen upplöst för din plattform.

## Öppna genvägshjälpen snabbt

Tryck **F1** eller **Primär + ?** för att öppna genvägsreferensen utan att
lämna ditt pågående arbete. **Primär** betyder Command på macOS och Control
på Windows eller Linux.

Ofta användbara appövergripande kommandon är bland andra:

| Åtgärd | Genväg |
| --- | --- |
| Öppna kommandopaletten | Primär + K |
| Skapa en textpost | Primär + N |
| Skapa en uppgift | Primär + T |
| Öppna Uppgifter, DailyOS, Projekt eller Vanor | Primär + 1 / 2 / 3 / 4 |
| Öppna Insikter, Loggbok, Evenemang eller Inställningar | Primär + 5 / 6 / 7 / 8 |

Enskilda sidor lägger till kontextuella kommandon som spara, uppdatera, sök
eller skapa. Deras tillgänglighet kan bero på vad som just nu är fokuserat
eller om det finns osparade ändringar.

## Kör ett kommando utan att lämna ditt arbete

Tryck **Primär + K** för att öppna kommandopaletten ovanpå den aktuella
sidan. Den kombinerar appövergripande åtgärder — skapa poster, öppna
uppgifter, navigera och zooma — med kommandon från den aktiva sidan.

  caseId="keyboard-shortcuts/palette"

Börja skriva för att begränsa listan efter åtgärdsnamn, grupp eller
tangentkombination. Använd upp- och nedpilarna för att flytta markeringen,
**Enter** för att köra kommandot och **Escape** för att stänga paletten.
Eftersom paletten är kontextuell visas ett kommando som **Spara** bara när
den fokuserade redigeraren faktiskt kan spara.

## Sök efter åtgärd eller tangent

<ManualScreenshot
  caseId="keyboard-shortcuts/search"
  alt="Lottis katalog över tangentbordsgenvägar filtrerad med en sökfråga"

Använd sökfältet när du känner till antingen åtgärden eller en del av dess
tangentkombination. Katalogen i appen är auktoriteten om en bindning ändras i
en senare version av Lotti.
