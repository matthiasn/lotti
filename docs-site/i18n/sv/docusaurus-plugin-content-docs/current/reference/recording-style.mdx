# Välj en inspelningsstil

Öppna **Inställningar → Inspelningsstil** för att välja visualiseringen som
visas medan Lotti spelar in ljud. Detta ändrar bara presentationen; båda
stilarna representerar samma inspelningsprocess.

## Jämför de två stilarna

- **Modern** visar ett animerat energiklot som reagerar på den aktuella
  nivån.
- **Analog** visar en traditionell VU-mätare med en rörlig nål.

Välj endera kortet för att göra det till den aktiva stilen. Det finns ingen
separat spara- eller fortsätt-åtgärd.

## Förhandsgranska med din röst

Aktivera **Prova med din röst** för att driva förhandsvisningen från
mikrofonen. Tala på det avstånd du räknar med att använda när du spelar in
och se hur den valda visualiseringen svarar. Stäng av alternativet när du är
klar med att jämföra stilar.

Förhandsvisningen hjälper dig att välja ett visuellt språk; den är inget
kalibreringsverktyg för ingångsnivå eller inspelningskvalitet. Se
[Spela in ljud](../plan-and-capture/recordings.mdx) för själva
inspelningsarbetsflödet.
