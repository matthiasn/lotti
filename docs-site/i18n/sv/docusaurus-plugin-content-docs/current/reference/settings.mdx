# Hitta inställningar

Inställningarna är grupperade efter den förmåga de styr. Skrivbordet använder
ett beständigt träd med den valda sidan bredvid; mobilen använder en
fokuserad lista och öppnar en inställningssida i taget.

Välj **Manuell** i den sista delen av Inställningar för att öppna den här
guiden i din standardwebbläsare. På macOS ger **Hjälp → Manual** samma länk.
Guiden följer ditt systemspråk som standard; välj ett annat språk i
**Inställningar → Avancerade inställningar → Språk** vid behov.

Vanliga destinationer är bland andra:

- **[Utseende](./appearance.mdx)** för ljust, mörkt och automatiskt visningsläge
  samt fler oberoende temapaletter.
- **[Inspelningsstil](./recording-style.mdx)** för energiklotet eller den analoga
  mätaren som visas under inspelning.
- **[Tal](./speech.mdx)** för rösten, modellen och hastigheten på enheten som
  används för att läsa upp uppgiftssammanfattningar.
- **[Kortkommandon](./keyboard-shortcuts.mdx)** för den sökbara katalogen över
  skrivbordskommandon.
- **[Slutförandefiranden](./completion-celebrations.mdx)** för animationer,
  haptik, stilar och deras interaktiva lekplats.
- **[Avancerade inställningar](./advanced-settings.mdx)** för funktionsflaggor,
  loggning, underhållsåtgärder, onboardingdiagnostik och bygginformation.
- **Kategorier** för planeringsgränser och **Etiketter** för tvärgående taggar.
- **Habiter** och **Instrumentpaneler** för reflektionsstrukturer.
- **AI-inställningar** för leverantörer, modeller, profiler och färdigheter.
- **Daily OS** för planerarens inferensprofil och hälsning.
- **Synk** för anslutning och aktivitetsstatus.

Den exakta uppsättningen kan variera med plattformens förmågor och aktiverade
funktioner.

## Hantera definitioner

Öppna **Inställningar → Definitioner** för att hantera strukturerna som
organiserar din data. Kategorier sätter planerings- och integritetsgränser,
etiketter taggar uppgifter över kategorier, vanor definierar återkommande
rutiner, instrumentpaneler ordnar reflektionsvyer och mätvärden definierar de
siffror du följer över tid.
