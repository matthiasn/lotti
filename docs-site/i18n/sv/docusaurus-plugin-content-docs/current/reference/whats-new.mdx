# Bläddra bland vad som är nytt

Vad är nytt presenterar versionsnoter inuti Lotti, matchade mot den version
du kör. Den kan öppnas automatiskt efter en berättigad första start eller ett
versionsbyte, och den finns också tillgänglig via posten **Vad är nytt** i
Inställningar när den förmågan är aktiverad.

Versionsnoterna ordnas nyast först. Varje sida kombinerar en releasespecifik
hjältebild, dess exakta appversion och en kort redogörelse för de synliga
förändringarna för användaren.

## Läs den aktuella utgåvan

Versionsmärket identifierar den utgåva vars noter visas på skärmen. **NYTT**
markerar den senaste utgåvan i den aktuella uppsättningen; det betyder inte
att varje punkt på sidan är ofärdig eller experimentell.

Brödtexten rullar oberoende när utgåvan är längre än den tillgängliga höjden.
Länkar använder Lottis vanliga länkhanterare, och bilder förladdas när det
går, så att det förblir smidigt att röra sig mellan utgåvorna.

Använd sidfotskontrollerna för att navigera:

- den högra vinkelpilen öppnar nästa äldre utgåva;
- den vänstra vinkelpilen går tillbaka till en nyare utgåva;
- positionsmarkörerna visar var den aktuella sidan ligger i den laddade
  uppsättningen;
- **Hoppa över** stänger en uppsättning med flera utgåvor före sista sidan
  och markerar hela den laddade uppsättningen som sedd; och
- **Klart** visas på den äldsta sidan och markerar också hela uppsättningen
  som sedd.

Att stänga modalen genom att dra bort den eller välja det nedtonade området
omkring är mer försiktigt: Lotti markerar bara de utgåvor du faktiskt nådde,
till och med den sida du kom längst till. Utgåvor du inte nådde kan därför
dyka upp nästa gång Vad är nytt öppnas.

## Återbesök noter du redan avfärdat

När inga osedda utgåvor finns kvar visar Vad är nytt läget **Du är helt
ikapp**. Välj **Visa tidigare utgåvor** för att rensa de lokala
sett-markörerna och bläddra i den tillgängliga utgåveuppsättningen igen. Det
ändrar bara den lokala versionsnotshistoriken; det ändrar inte den
installerade appversionen och laddar inte ner något annat bygge.

Vad är nytt visar aldrig noter för en utgåva som är nyare än den installerade
Lotti-versionen. Om utgåveinnehållet inte kan laddas faller appen tillbaka
till ett tomt läge i stället för att presentera noter för fel bygge.

För exakt byggnummer, plattform, lokala postsummor och uppgiftsantal, se
[Om Lotti](./advanced-settings.mdx#verifiera-bygget-och-de-lokala-totalerna).
