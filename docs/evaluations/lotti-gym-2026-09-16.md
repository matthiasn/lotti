# LottiGym, 2026-09-16: every section run and optimised

One pass over the whole catalog for both production candidates, the defects it
found, and the same pass repeated after fixing them. Every run is in
[`lotti-gym-runs.jsonl`](lotti-gym-runs.jsonl); the run ids below identify the
rows.

The control model `glm-5.3:speed` was run once over the full catalog
(`20260915T223011Z-5604e54a`). It exists to tell a harness or scenario defect
from a small model's limits: when the strongest model fails what the flash
models pass, the scenario is usually wrong. That is exactly how the
`day-planning` contract gap and both `task-directives` fixture defects were
found.

## What the baseline found, and what was changed

Every fix below was made because a run failed, and every one is either a
harness defect (the eval was wrong) or a production defect (the app was wrong).
No scenario was relaxed to make a model pass.

**Production defects, all user-visible:**

- **A pinned `tool_choice` lost the call on DeepSeek** (#4307). Seven places
  insisted on one tool — the goal report and ad, the task report, the report
  editor, the event report, the day capture-parse and draft, and the audio
  summary. DeepSeek answers a pinned choice with `<｜DSML｜ invoke …>` text and
  an empty `tool_calls`, so the app saw nothing and the wake ended with nothing
  saved. Measured across both flavours and both GLM models: only DeepSeek
  breaks, and only when the choice is pinned. This is what took compaction's
  status accuracy from 24/30 to 29/30.
- **A goal report saying "recovering" or "achieved" was refused** (#4301).
  The prose guard banned every status name, but two of them are ordinary
  English, so a recovering goal's report was rejected and lost. `goal-outcomes`
  27/30 → 30/30.
- **A stray backslash broke a whole query answer** (#4304). Models escape
  markdown dashes (`\-`); strict JSON parsing rejected the response outright.
  GLM's entire query section could not be measured before this.
- **An out-of-scope action target discarded the answer** (#4304). A proposal
  naming another task's entry threw past the answer, so chat showed an error
  instead of what it had found. The answer now survives with no actions.
- **The day planner had no rule for an empty plan** (#4303). The writer
  rejects an empty draft while the window is open, but nothing said so, so the
  model sent one, was rejected, and sometimes invented filler blocks. It now
  sends a single explanatory buffer block. `day-planning` 14/24 → 19/24.

**Harness defects — the eval was measuring itself:**

- Compaction scored the first response only, where production sends a pinned
  forced-report retry (#4302), and it now judges a report by whether the
  production strategy *accepts* it.
- German deferrals read as completion claims: modal passives (#4300, #4305),
  `außen vor`, `keiner` (#4305). Each is now clause-scoped, so a negator cannot
  excuse a claim in another clause.
- A `day-planning` scenario required work the model was never shown (#4303),
  and two capacity scorers misread honest partials.
- Two `task-directives` fixtures contradicted themselves (#4305), which only
  the control model was careful enough to fail.
- A goals scenario demanded a banner tone the contract binds to a different
  branch (#4302).
- One flaky `HTTP 503` on the preflight probe abandoned a whole run (#4308);
  transient failures now retry up to three times, permanent ones still stop at
  once.

## Judged: compaction

The deterministic gate is status accuracy; fact recall and recommendation
quality need a judge. Graded by Claude Opus 5 against the packet's answer key,
on `20260916T004737Z-ce62d109` (DeepSeek, 30 cases, 180 probes):

| Arm | Old-fact recall | All ages | Hallucinations | Agreement with full | Wake input | userVoice at 24 months |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `full` | 100% | 100% | 0/90 | — | 45,659 | 7,722 |
| `hierarchical` | 95% | 96% | 0/90 | 15/15 same | 13,755 | 2,003 |

**Hierarchical passes every criterion of the pass bar.** It keeps the substance
at about a third of the wake tokens. Its five partial answers all lose a
*cause* while keeping the fact — it knows the calendar block was deleted on
5/23 but not why — and its one honest-unknown is a refusal to guess, which the
rubric does not punish.

That grading predates #4307, so it measures recall and agreement, not the
report loss that fix repaired.

## Remaining failures, and why they stand

- **`goals/cx_gym_done_steps_collapse`, GLM, 2/3.** The model retires the stale
  ad and writes the banner, then stops before the report. Production recovers
  it with the forced retry; tier 1 has no retry by design. The prompt is at its
  length cap and three earlier edits were reverted after full-suite damage.
- **`compaction`, GLM, 9/30.** GLM returns a structured report with only
  `tldr` and `rollingWindow`, so production's parser refuses it and nothing
  persists — the same refusal the eval now scores. A real weakness of that
  model in a long-context wake, not a harness defect.
- **`day-planning`, 5 (DeepSeek) and 9 (GLM).** Capacity arithmetic and
  restraint, plus one inference timeout. The contract gap is fixed; what is
  left is genuine.
- **`task-conversation/user_completed_item_resurfaced_production`, GLM, 1/3.**
  A mild overclaim: "root-cause investigation now underway" when nothing shows
  it started. The checker is right.
- **`query-actions/time_start_edit`, GLM, 3/3.** Deterministic, and not yet
  diagnosed.

## Still open

- **`day-journey` has no grader.** Its artifacts already carry capture recall,
  planned task ids and status events — enough for objective checks on recall,
  required work placed and nothing silently dropped. Until then it can only
  report `review_required`.
- **Compaction needs a judge to reach a verdict**, so a run without one is
  always `incomplete`. The grading above is manual and has to be repeated per
  run.
- **A tier-2 relationship suite** — scoring what the workflow persists rather
  than what the model says — remains unbuilt.
- **Vision, speech, relationship persistence and applying query actions** stay
  the catalog's declared coverage gaps.
