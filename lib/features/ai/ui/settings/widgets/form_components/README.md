# AI form components

Shared form controls for the AI configuration pages — provider, model and profile
forms — so they have one visual language, one way of showing errors, and one
keyboard and screen-reader behaviour.

They bridge into the [design system](../../../../../design_system/README.md)
rather than restyling controls locally.
