# Recording UI

The visible part of recording: a live level display, the record and stop controls,
and the status indicators that appear elsewhere in the app while recording.

The level display comes in two styles — an analog VU meter and an energy orb —
chosen in *Settings → Recording Style*. Both are driven by the same live signal,
so they can never disagree about the level.
