# Recording UI

The visible part of recording: one recorder on every surface — a live level
line over the discard, timed Stop and pause controls — and the status
indicators that appear elsewhere in the app while a take runs.

The recorder starts the take as it opens, and shows no orb, no meter, no hint
and no model name: the sheet's title says what the recording is about.
