# Selection widgets

Reusable pieces for building consistent selection modals, plus the unified
toggle/switch family.

They exist because several modals had each grown their own option row with
slightly different padding, selection markers and semantics. One option anatomy
now serves them all, and it is the same anatomy
`DesignSystemSelectionRow` builds on.
